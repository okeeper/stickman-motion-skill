# 导演方案、分镜与逐镜提示词

此文用于 A · 导演及 B · 制作的前期规划。参考 `stickman-video-director` 的导演方案、镜头清单与自包含提示词结构；以小黄人的探索为主线，默认通过空间现象而非画内公式、术语或结论直接讲知识，不强制十秒一镜。用户要求方案、剧本或提示词中的哪一部分，就交付哪一部分；已有授权下继续完成任务。

## 导演方案

围绕同一故事，写清主题、观众、片长预算、画幅、角色目标、核心看点、知识前提、视觉/声音方向、开场问题与结尾变化。区分原创设定与受参考片启发的方法。选择对象关系、尺度探索、视角回收或其他适合题材的结构；写因果梗概而非只列名词。已定参数不反复询问，风格和画幅能合理推断时说明默认。

建立简短连续性卡：角色身份与形态；重要对象 ID、形态、当前数值或位置；场景坐标及视角；每件道具的持有者；声音处理和调色；哪些事件会改变状态。两个外观相同的符号也可能是不同对象。必要时附“前段线索—首次理解—后段作用/新理解—产生该变化的行动”。

## 剧本与分镜

按实际事件安排时长，允许长短不一。每个关键镜头写：

| 字段 | 应能回答的问题 |
|---|---|
| 时间预算与镜头任务 | 这一镜改变了什么，为什么需要这个景别和时长？ |
| 入镜状态 | 人、对象、道具、位置、朝向及已知信息是什么？ |
| 画面与表演 | 人物意图、注意对象与心理转变如何由姿态、重心、朝向、速度、距离、停顿、接触及反应显现？ |
| 探索与观众体验 | 小黄人尝试了什么、是否误判、经历什么情绪；观众此刻知道什么、可能产生什么猜测？ |
| 空间机制与后果 | 后台关系及条件是什么，现象如何通过局部行动逐渐出现；结果怎样改变下一次探索？ |
| 镜头和声音 | 注意焦点怎样转移；动作声、对象反馈、环境、音乐、留白如何跟具体帧或动作节拍衔接？ |
| 出镜与连接 | 人、物、动量、信息或时间如何延续；明确切镜/时间跳转的变化？ |

重点表演另列动作谱，写明关键帧或时间、支撑变化、接触与反应的先后、动作余势和新的选择，方法见 [表演与动作设计](performance-and-animation.md)。情绪由角色间距、手势、躯干、注意方向和节奏表达，无脸人物不必凭空添加五官。不要在镜头之间重置持有关系、受伤或空间位置。远景展示关系、近景展示操作；不让特效或字幕遮挡关键信息。空间扩大时保留熟悉物作为参照；需要看清新规则时留出适当时间。

每一镜可以有不同数量的动作，不要求固定三段、固定视觉变化次数或每镜强行运动。用可播放时间预算而不是空泛的“炫酷一战”。需要旁白时将准确台词、说话人及声音轨单独列出，按实际录音调整镜头，不改变已接受音频的语速以凑镜长。

## 单镜生成提示词

仅当用户要求外部生成提示词或选用视频生成模型时，对每个生成片段给出独立可用的提示。片段长度取决于实际故事和工具能力，重要操作可拆镜重试。

1. 时长、画幅、角色与目标视觉风格；角色和关键道具的简洁一致性描述。
2. 场景、初始位置、支持物、视角、前一镜的入口状态。
3. 按时间顺序描述人物实际动作、接触位置、对象反应与结果；关键对象保持稳定身份。
4. 镜头移动的目的、空间方向、需要保留的阅读/反应时间；结尾姿态、位置、持物和去向。
5. 角色、音乐与实际动作音效的需求；有配音时重复精确台词和角色/声音设置，无台词时明确不生成讲话。
6. 避免多余肢体、角色变形、关键接触漂移、重复对象等，针对本镜实际风险编写；默认不直接展示知识术语、公式或结论，用户明确要求时除外。
7. 如果用户要求画面呈现公式、数值、单位或复杂示意图，将其单独列为可编辑叠层和手工校对项；如果工具确能精确呈现并经画面验证，可留在生成素材中。给拼接说明：上一镜末帧 → 本镜首帧，若跳时或换景则写清所变和所继承内容。

提示词可以使用用户要求的语言；工具偏好另一语言时，可同时给出等义版本。提示词不证明生成内容连续或科学准确。对手、长镜头和戏剧性音效应由故事需要决定。
