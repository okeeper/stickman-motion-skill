# 知识机制与场景规格

为故事中的关键知识关系提供可核验的表达。先按 [导演与剧本](concept-story-directing.md) 确定人物、遭遇和事件，再给每个真正影响剧情的机制写下列字段；普通观察或反应无需强加数学标签。

| 字段 | 需要写清的内容 |
|---|---|
| 知识命题 | 真正成立的关系是什么；引自哪里或如何推导？ |
| 前提 | 定义域、单位、坐标、范围、分支、介质、近似和边界情况中哪些与本镜有关？ |
| 对象与身份 | 哪些是可接触的角色/道具，哪些是表达式、图像或标注？重复外形如何区分？ |
| 输入与操作 | 角色实际触碰、修改或观察什么；哪个输入发生了变化？ |
| 输出和反馈 | 条件满足后出现什么结果，观众如何看到或听到？ |
| 身体接触与持续状态 | 人物手脚、支撑、对象位置、持有者、运动与代价如何延续？ |
| 知识和故事边界 | 哪些是数学或物理结论，哪些是空间具象化、拟人或科幻约定？ |
| 后段作用与核验 | 该发现如何影响后文；哪些命题已核算，哪些仍需测试或人工审看？ |

同一画面可有不同层次：例如符号的外形作为道具转动，与它代表的数在复平面上的旋转不是同一个事实；动画需要给出明确映射，不能因字形转动便宣称数学证明。

## 四类语义操作

1. `expression_edit`：将一个表达式修改成另一个，如把 `1+1` 改成 `1×1`；结果应基于新表达式重新计算。
2. `evaluate`：在给定输入和约定下求当前表达式的值，如 `1+1=2`。
3. `equivalent_rewrite`：在明确条件下将表达式改写为具有相同含义的形式，如对实数 `x`，`x+x=2x`；应检查该等价所需假设。
4. `spatial_metaphor`：将概念映射成空间、行为或戏剧现象，如把波形画成角色身边可见的线。明确这是可视化或世界约定，不能直接当作现实介质模型。

一个连续动作可以包含多个操作：标清先编辑、再求值的时刻，也可以在不改变数值的条件下换一种表示。插值或绘制中的过渡画面不一定是成立的等式，不能把每帧都当作有效推导。

## 核验尺度

- 数学：明确数域、定义域、分支和收敛等前提；有限数值检查不能替代一般证明。
- 物理：给出单位、理想化模型、受力和守恒条件；角色在图形上行走等属于创作设定。
- 算法：给出输入、前置条件、关键不变量、边界与输出，保留可复现的输入示例。
- 时间与接触：在实际画面检查运动方向、道具身份、接触、支撑和下一镜承接；清单字段或关键帧存在并不证明动作可信。
- 视频：文本自审、数值检查、编码解码、连续帧、正常速度观片、完整听审和观众理解测试分别记录；动画不是证明自然规律的实验证据。
