# 概念冒险视觉与声画语言

参考 [两片分析](../docs/concept-film-analysis.md)。默认主角是贯穿故事的小黄火柴人；背景、空间材质和镜头风格随故事选择，用户明确指定其他角色时遵循用户要求。黄色要在每镜保持一致并与环境可辨；使用内置 `stick` 时可显式设置黄色 `color`，默认也是黄色 `#ffd43b`。

**角色与对象**：用清晰、稳定的小黄人轮廓和对比色让注意点可辨，角色有可读的注意方向、重心、手脚支撑、接触与恢复。让环境和物体通过运动、接触、阻力或其他可观察的反馈逐步体现关系；不要默认使用公式、标签、完整示意图或直接讲解。用户要求显式符号时，应区分可拿的字形、表达式与叠加说明。图层 ID 不会自动提供知识语义或接触约束。

**构图与动作**：先让观众看到目标、身体和支点，再展示操作及反馈；近景处理手与具体符号，中景看双方动作，远景展示尺度和结构。镜头移动要有明确阅读目的。局部反应、短暂停顿、快攻防和尺度拉远按剧情交替；快速动作仍需要清楚的关键姿态与前后关系。人物关节插值并不自动具备骨长、碰撞、重力或接触物理。

**知识空间**：先建立幕后模型，再让人物从局部行动逐渐遇到它的不同侧面；物体的反馈和逐步打开的空间让观众自己建立关系，不抢先画出全貌。扩大尺度时保留熟悉对象、路径或小黄人作为参照。同一对象或细节在后段产生可追踪的新作用，或者新视角补上此前缺失的来源。前提、近似、定义域和隐喻分别记录。

**声音**：无台词不意味着无声音。以接触、移动、环境、概念反馈、音乐与留白分别组织事件，重要动作前后留出观看和聆听的空间。运行时支持少量程序音效和用户自有声源；固定音色不自动等于原片音质，未实际听辨的原声不能声称已复刻。使用自行创作或获许可的声音。

**不能自动保证**：内置画面图层和正反向高斯波只是明确的低层工具；不是原片复杂动作、任意公式求值器、宇宙三维场景或成片质量的保证。新物理、复杂手部接触、相机透视及电影级表演要另行制作、动态试做并审看。
