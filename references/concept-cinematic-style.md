# 概念冒险视觉与声画语言

参考 [两片分析](../docs/concept-film-analysis.md)。风格取决于故事和用户的选择；以下是起点，不规定每片必须黑底、橙色或出现相同角色。

**角色与对象**：用清晰、稳定的火柴人轮廓和对比色让注意点可辨，角色有可读的注意方向、重心、手脚支撑、接触与恢复。符号可能是可拿的字形、表达式的一部分或主动角色；同一符号改变身份时画面要交代操作和结果。物理量可用箭头、曲线、轨迹及注释显示，注释不一定是角色可抓取的物体。图层 ID 不会自动提供知识语义或接触约束。

**构图与动作**：先让观众看到目标、身体和支点，再展示操作及反馈；近景处理手与具体符号，中景看双方动作，远景展示尺度和结构。镜头移动要有明确阅读目的。局部反应、短暂停顿、快攻防和尺度拉远按剧情交替；快速动作仍需要清楚的关键姿态与前后关系。人物关节插值并不自动具备骨长、碰撞、重力或接触物理。

**知识空间**：数学片启发之一是让数、符号、轴、圆与波形沿既有关系产生新表示；物理片启发之一是把身体运动扩展到地形、工具、天体和更抽象的空间。扩大尺度时保留熟悉对象、路径或角色作为参照。同一对象或细节在后段产生可追踪的新作用，或者新视角补上此前缺失的来源。前提、近似、定义域和隐喻分别记录。

**声音**：无台词不意味着无声音。以接触、移动、环境、概念反馈、音乐与留白分别组织事件，重要动作前后留出观看和聆听的空间。运行时支持少量程序音效和用户自有声源；固定音色不自动等于原片音质，未实际听辨的原声不能声称已复刻。使用自行创作或获许可的声音。

**不能自动保证**：内置画面图层和正反向高斯波只是明确的低层工具；不是原片复杂动作、任意公式求值器、宇宙三维场景或成片质量的保证。新物理、复杂手部接触、相机透视及电影级表演要另行制作、动态试做并审看。
