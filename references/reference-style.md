# 参考片的视觉、表演与叙事语法

历史风格参考：本文针对《Animation vs. Math》的概念冒险。现行入口使用 [两片分析](../docs/concept-film-analysis.md) 和 [导演与剧本](concept-story-directing.md)，按题材选择外观和事件；用户指定的风格优先。身体动作的连续帧观察见 [重量研究](../docs/weight-motion-study.md)。

故事开发以当前导演方法为准；[原片仿写提示词 A/B/C](reference-screenwriting-prompts.md) 为可选的历史配置。

## 第一判断：知识有没有改变人物的处境

让数字、运算符、图形和坐标成为人物能够接近、拿取、推动、连接、躲避或借用的对象。一次操作需要同时改变世界状态与人物接下来的可选行动。人物通过操作与反馈获得能力，观众通过结果理解规则。

例如：人物先看到移动支撑的方向，带上一个方向因子，登上支撑后把因子装入运算槽。符号运算改变方向设置，平台制动与反向加速，人物重新平衡，最后借平台速度离开。这段的知识、道具和动作属于同一条因果链。

若去掉人物后，整段依然只是公式逐条出现，优先重写人物的介入方式。必要的严谨推导可以保留稳定镜头与短暂停顿，让人物有理由测量、比较、验证并使用结论；较长的完整证明也可以作为随附文件。用户明确要求讲解片时，不强行改成动作片。

## 画面：黑色空间、清楚轮廓和有身份的符号

参考配置为纯黑或接近黑色的空间、白色知识对象、橙色主角；细灰线交代轴、轨道、刻度或空间结构。先靠位置、明暗、粗细和运动建立层级，颜色用于有意义的区别。默认不将卡片、标题栏、进度条和调试读数画进成片；播放器和制作检查界面可以保留这些控件。

留白是行动、阅读和未知的空间。角色可以很小；需要读清一次拿取或编辑时，相机再靠近。先建立稀疏规则，复杂结构从已有对象长出，密度随情节变化。大面积白光、密集网格、粒子和镜头震动要有事件来源，使用之后恢复可读性，不把强效果铺满全片。

符号有稳定对象 ID、位置和状态。角色拿走的那个符号，后面仍能被追踪；必要时显式复制为新 ID。乘号和字母 x、负号与连字符、指数与正文采用清楚排版。控制值、实际运动和用于解释的图形分别存储，不能因为画面都是箭头就混为同一变量。

## 身体：先有意图，再有动作，最后处理后果

用对象与身体的关系表达心理：注意先落到什么地方，手是否在接触前停住，髋部是否仍保留退路，脚什么时候交出重量，确认安全后肩部怎样松开。无表情不等于持续摆手，也不需要给每种情绪配置图标。

重点动作写清：观察和判断 → 支撑与预备 → 发力和执行 → 接触 → 卸力、调整与重新判断。一般的小动作不必机械套齐六个阶段。人物可以俏皮或误判，但其当时的选择要说得通；不靠忘记规则和重复无效操作制造趣味。

身体各部分有先后：髋、躯干、肩、头与手脚可由不同的受力响应和表演轨道驱动。夸张来自发力、路线、时机和轮廓变化；保留准备与承受后果。允许非对称收腿、扭转、翻滚等动作，但引擎尚未实现的动作应明确实现与试做，不能靠关键词声称已有。

接触优先于修饰：

- 承重脚绑定地面或移动支撑的局部坐标；支撑移动时脚随支撑移动。
- 手绑定实际把手或物体上的抓点，物体跟随求解后的腕部；释放时交出连续位置和速度。
- 腾空按世界时间推进重力，继承起跳时已有的载体速度；避免给整段飞行套缓入缓出。
- 落地先保留速度，再通过压缩、阻尼、主动调整或下一次发力处理动量。
- 片段交接继承上一段身体方向与状态；过渡上身姿态时不混合两个不同的承重脚位置。

## 故事：理解规则就是获得行动能力

具体编剧时使用 [因果剧本](cinematic-storytelling.md) 和 [剧本工作台](story-workbench.md)，原片的逐段依据见 [故事拆解](../docs/reference-story-analysis.md)。规则被学会之后，仍要发展新的处境与观众期待；同一对象可以换用途、改变控制权或与人物形成不同关系。不要只用增加操作次数来延长探索。

长片可以形成探索、规则扩展、压力升级、组合运用、高潮和余波；这不是每个主题必须凑齐的章节。短片聚焦一个完整因果回路即可。一个符号开始只是可操作物，后面可以成为工具、阻碍或有自主行为的对象；角色与它的关系也可以变化。

表达式成为对手时，给它自己的目标、能感知的信息、行动征兆和规则限制。它会回应人物的选择，能力来自已建立的数学结构；主角可以拆解、改写或组合已有规则改变对抗条件。不要让它停在原地等待表演，也不随意新增恰好克制主角的招式。对抗转为合作时，用靠近、交出控制、接受帮助或共同操作表现关系变化。

第一次介绍规则时保持可读，观众熟悉后加快复用。引入新条件应改变原有解法的效果或代价，高潮使用的规则与能力提前铺垫。升级可以发生在策略、空间、规模、关系或身体压力上，不只增加公式数量。

普通观众应能读出谁想做什么、什么阻挡了他、操作产生了什么结果；熟悉知识的观众还可以读出准确的概念关系。重要的新命题留出理解时间，高潮背景不要求每个字符都完整读完。知识密度与运动强度不同时无差别拉满。

幽默来自认真行动时的预期落差、性格和关系，不用奖品、随机先试错或胜利姿势替代结尾。结果后留出身体恢复与重新理解对象的时间。

## 镜头：操作、行动和尺度各有依据

近景让观众看清接触与符号改变；动作景别保住行动双方、目标和落点；远景借主角、坐标或已有物件显示世界规模。相机改变前要知道观众接下来需要理解什么。

优先让点展开为轴、线绕成圆、路径长出结构等对象行为连接场景。相机的缩放不能承担所有变化；空间关系不清楚时先建立方位。不要固定每几秒切镜，不要求所有场景连续形变。文字刚进入关键变化时避免同时剧烈摇镜。

## 声音：接触、规则、段落分别设计

参考片的音乐和声音设计分别署名；对公开配乐的确认见 [作曲者页面](https://www.scottbuckley.com.au/2023/06/animation-vs-math/)。已有研究仅核对署名及分段信号能量，不能当成对原片乐器、音色或逐项音效的听辨报告。以下是本项目的制作方法。

| 层 | 对齐的事件 | 要表达的区别 |
|---|---|---|
| 接触与位移 | 落脚、拿取、松手、起跳、碰撞、摩擦 | 轻重、速度、材质、距离；不同事件不共用一个提示音 |
| 符号与机制 | 求值完成、方向设置变化、结构展开 | 规则已经生效，反馈区别于普通身体接触 |
| 段落音乐 | 探索、等待、执行、危险、发现、余波 | 留出空隙、建立张力、结果后回落，避免循环底音贯穿所有情绪 |

声音 cue 从实际接触和状态事件生成，不另写一个猜测的时间表。脚步跟着落脚；只有显著碰撞才给较强低频和尾音。声像可以随画面位置变化，关键接触和规则反馈出现时音乐短暂让位。避免提前泄露悬念或用音乐掩盖不清楚的因果。

先静音检查意图和作用关系，再有声检查音画同步、重轻差别和疲劳感。完整听审、响度指标、主观材质判断分别记录；RMS 与峰值不能证明音乐好听、动作有重量或混音具有电影感。

## 如何判定方向是否落实

对实际片段检查：

1. 人物是否通过身体行动直接介入知识对象？操作是否改变局面？
2. 静音并隐藏解释性文字，是否仍能辨认主要目标、接触、结果和调整？
3. 规则和人物能力是否在后段得到有准备的运用？条件变化是否引出新的判断？
4. 放大连续帧，脚、手、物体与支撑是否连接？离地、接触和片段交接是否连续？
5. 相机是否在必要时帮助读操作、看动作或感受尺度？画内界面是否挤占故事？
6. 声音是否对应真实事件，段落之间是否有强弱与空隙？

发现失败项时指出时间与具体问题，再修正。测试通过、使用 TS、60 fps 或配色相同，都不能替代这些判断。实际落地范围见 [《借势》样片](../demos/adventure/README.md) 与 [QA](../demos/adventure/QA.md)；它是单机制短片，未覆盖原片的大型对抗与复杂世界演化。
