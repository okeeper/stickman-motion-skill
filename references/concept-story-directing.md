# 概念冒险的导演与剧本

用于创意、完整剧本和改稿。工作目标是让故事可连续观看，知识关系真正影响行动；不强制所有故事采用同一场景、反派、考试结构或结尾。原片证据见 [两片分析](../docs/concept-film-analysis.md)，字段与交付见 [分镜与提示词](director-workflow.md)。

## 从两个方向同时构思

先明确题材、受众、目标时长、角色、交付与用户给出的限制。缺项能合理决定时自行决定，标明假设。写下两条简短的线：

- **知识线**：可被观察的性质是什么？哪些关系成立，需要什么假设？能否从已有对象进入另一种表示、运动尺度或观察视角？
- **体验线**：主角当前要做什么？观众此刻想知道什么？哪一次行动改变了可用选择？结尾让主角和观众重新认识了什么？

将两条线交会在具体事件上。给事件写“起始状态 → 可见动作 → 对象/环境的具体反应 → 人物改变办法或处境”；不能只填“发现”“震撼”“打斗”。事件之间要能指出上一事件留下了什么，让下一事件有机会或必要发生。

## 按题材组合叙事结构

**对象关系型**：一个知识对象先作为可接近的东西出现，后续体现意料之外的能力或限制。角色与它的关系可从玩耍变为对抗、协商、理解或合作；对象在每次再出现时最好改变人物能做的事，而不是机械重复。数学片的符号操作、对象主动回应及末段重新接触，是可分析的例子，不是复制剧情的要求。

**尺度探索型**：从一个身体动作、局部测量或普通工具开始，让运动和后果将角色带入新的空间尺度。新尺度沿已出现的运动、物品或问题长出；保留人物、道具或轨迹作为观众的参照。物理片的地面运动、火箭与天体、后续时空视角是例子。空间越来越大并不自动等于剧情升级：每个新尺度要改变观察、代价或可行动作。

**视角回收型**：先让一个细节有清楚的表面作用，同时保留可观察但未解释的来源；后段通过新的视角、关系或操作补上信息。列出时间顺序：谁在何时能看到什么、能否影响先前事件、早期画面有哪些证据。明确这是故事对时间的设定；不要把外形相同的角色自动断言为同一个人，或把所有再次出现称为因果闭环。

三种结构可以组合，也可以只选择其一。短片允许一个发现和一次情感变化，不强行加入敌人、无限升级、长回收或冒险出口。

## 构思底稿

```text
题材与受众 / 时长预算 / 交付范围：
主角当下的处境和想要完成的事：
观众最先看到的异常和最自然的问题：
能够用动作体验的核心性质 / 成立前提：
核心对象或环境的身份、可用方式与限制：
关键事件：行动 → 具体回应 → 新局面 → 下一选择：
新表示、尺度或视角如何从前一事件长出：
后段实际使用了什么前期发现 / 对象作用如何改变：
结尾回答了什么，哪个问题有意保留：
```

用户只要创意时交付有区别的概念和关键事件；要完整剧本时继续写连贯故事、可拍摄分镜、规则假设和试做风险；只要改稿时保留既有有效内容，重写具体薄弱事件。

## 用动作承载感受

先写注意和目标，再写接触点、支撑、路径、反作用及恢复。人物需要有判断、速度、重量、玩心和失败后的应对；没有五官时，通过头部朝向、姿态、距离、手的迟疑与身体节奏表达。对抗时写清彼此相接的动作和办法变化；探索时让停顿带来判断、线索、预期或关系变化。允许角色安静地观察、等待或体验。

符号可以是文本、可抓取的几何形状、运算符或有自主性的角色，但这些身份的切换需要可见。箭头和数值可以是叠加的测量说明，不必都成为能抓取的物体。几何线、图像和人物踩踏/穿行的关系要标为模型事实或空间隐喻。场景奇观服务正在发生的事；新公式不可只是效果装饰。

## 可直接用的创作指令

**构思及分镜**：

```text
使用 $stickman-motion-skill，以【主题】为核心，面向【受众】，制作约【时长】的【无台词/有旁白】短片。先形成有具体因果的原创故事，再写分镜、知识前提和声音设计。选用适合题材的对象关系、尺度探索或视角回收；每次知识变化写出角色如何触发、看到什么结果、如何改变行动。对高风险动作标出试做方案；本次只交付文本。
```

**改写**：

```text
使用 $stickman-motion-skill 审改以下剧本：【剧本】。指出最弱的具体一到三处事件，解释人物选择、知识关系或前后因果为什么不足，直接重写这些事件及必要衔接；保留成立的设定和用户指定风格。区分已知事实与故事约定，不用增加公式数量或口号替代戏剧变化。
```

## 交付前自审

逐项找实际事件作为证据：主角目标是否可见；观众有无可跟随的问题；新对象和新尺度是否有来源；重要动作的接触、结果和代价是否连续；至少一个关键发现是否影响后续事件；结尾的新信息是否由前文支持；数学/物理前提和艺术约定是否分开。用“删去这一发现会影响后段哪一个动作”检查回收的必要性。某个结构不适合短片时可以不用，但不能凭条目齐全宣布观众一定看懂或喜欢。
