# 动作约束工具与三段试片

用于新片的侧面步行、伸手、跳落和推物预演。它们是有边界的几何与运动工具，不能从主题生成动画，也不能代替逐镜表演、一般碰撞解算或完整人体动力学。

## 制作与复现

在技能目录安装已有依赖，输出工程放在安装目录之外。目标目录必须不存在，不覆盖已有作品：

```sh
npm ci
node scripts/performance-trials.mjs /absolute/path/my-trials
node scripts/autopilot.mjs render /absolute/path/my-trials/01-curiosity/project.json
node scripts/autopilot.mjs render /absolute/path/my-trials/02-gap/project.json
node scripts/autopilot.mjs render /absolute/path/my-trials/03-weight/project.json
```

每支试片为 1280×720、24 fps、8 秒，含可编辑工程、原创程序拟音、空间底图和约束记录；导出仍走原有缓存、混音、编码和报告流程。三支分别练习走近与试探球体、观察缺口后起跳落地、两次发力后推动箱体。它们不是完整知识故事，不用换题材词的方式充当新片；新片要重编排探索、误判、情绪、空间机制和后果。

## 姿态与接触

`scripts/character-motion.mjs` 使用屏幕坐标，向下为正，以画幅的 1280 设计宽度计。`body` 根据骨盆、躯干倾角、头部倾角、双脚和双手目标求姿态；躯干 57、头颈 29、上臂/前臂各 36、大腿 44、小腿 46 为该侧面骨架的固定长度。`twoBone` 求肘膝位置并报告目标不可达距离；不可达时保持骨长，不静默拉长手脚。创作者应调整位置或动作，使关键接触可达。

`walk` 在平地用独立的世界坐标足底轨道交替摆动与承重，站立段不随骨盆平移；身体高度在可达范围内变化。它是编排过的步态，不是自动寻找地形的控制器。`flight` 对骨盆使用固定重力的解析抛物线，腾空阶段的时间不要再套平滑插值；手脚的收展、落地压缩、头身跟随另行编排。抓物时让物体与实际手腕共用状态；推物时为手和物体表面设同一接触位置，不各自独立移动后凭肉眼凑近。

按最终输出帧率求解并将完整姿态烘焙为 `jointsKeys`；试片在每个输出帧提供一个完整点集并使用线性关节插值。改变帧率应重新烘焙，中间时刻直接插值仍可能使骨长缩短。骨架约束保持的是关节几何，绘制的圆滑轮廓并非精确的人体表面或肌肉模拟。

## 已做的迭代和检查

本轮实际渲染三支小样并抽帧对照；第一轮发现普通站姿屈膝过度、推物时头靠进箱体边缘、部分臂部目标超出可达范围。之后提高站姿、调整发力倾角与手臂路径、修正步幅、为肘膝提供圆滑轮廓，并重新渲染。空间只保留一个主要目标和可见支撑面，以便观察接触；没有用文字、公式或装饰图层替代动作。

自动检查覆盖固定骨长、站立脚漂移、目标可达、推箱时头部不穿箱、足部不穿地和抛物线加速度；另测不可达目标、错误时间区间和输出目录已存在的失败路径。抽帧能检查指定姿态与接触，几何测试不能证明动作品质。完整正常速度的人工观片、完整主观听审和观众理解测试尚未完成；原创合成声也不等同于参考片的拟音品质。

## 下一镜仍须重新设计的部分

先选参考片里与本镜相似的动作功能，分析支撑、轮廓、动作先后、停留和余势，再原创编排。复杂翻滚、攀爬、移动支撑、斜坡、多人互动、角色旋转及镜头透视不在这套简单平地侧面工具的通用能力内，需要另行实现或换合适工具。即使骨长和接触正确，均匀节奏、重复手势、缺少犹豫和判断、过快复位仍会让人物像假人；这些必须通过镜头与表演修改解决。
