# 数学图形与连续动画

用于线条、人物轮廓、几何示意和公式动画。入口工程是 [motion/](../motion/README.md)，实际试片是 [《留下弧线》](../demos/geometry/README.md)。画得平滑、运动连续和数学正确是三件事，需要分别检查。

## 先定位问题

| 观察到的问题 | 应处理的层 | 实现方式 |
|---|---|---|
| 肘膝突然折角、线段接头生硬 | 几何轮廓 | Spline/Knot 的共同切线、有限长度控制柄，圆端点 |
| 线条圆滑但动作忽快忽慢或突然停住 | 时间与受力 | 速度边界、接触模型、身体跟随；物理时间不套全局缓动 |
| 函数曲线拐歪，人物和轨迹分离 | 建模与投影 | 同一参数、坐标和单位；精确曲线或有误差界的采样 |
| 字号、分数排版差，整行公式突然替换 | 数学排版与对象连续性 | LaTeX 矢量节点、子式分组、稳定阅读停顿 |
| 斜线爬行、细线闪烁 | 栅格采样与编码 | 足够线宽、较高内部尺寸、一次缩小，检查最终 MP4 |

不要用一个 `smoothness` 参数掩盖全部问题，也不向每个动作都加弹簧。弹簧适用于确有弹性或惯性跟随的部位，腾空位移仍服从该场景的重力模型。

## 当前工具选择

已接入 **Motion Canvas 3.17.2** 的 2D 节点、生成器时间线、编辑器和 LaTeX；LaTeX 由依赖中的 MathJax 3.2.2 生成 SVG。`motion/` 使用兼容官方插件的 Vite 5，`web/` 保留 Vite 8，不混用两套安装目录。

优先用内置 Spline、Knot、CubicBezier、Line、Circle、Latex 完成新场景。只有发现具体缺口再加库：复杂路径布尔运算可评估 Paper.js；React 交互数学页面可评估 Mafs；Python 科学动画可评估 Manim。本项目没有接入这三者，也不要求它们成为每个工程的依赖。

官方接口：[Spline](https://motioncanvas.io/docs/spline/)、[LaTeX](https://motion-canvas.io/docs/latex/)、[Motion Canvas 项目](https://github.com/motion-canvas/motion-canvas)。升级依赖后重跑构建、拖帧和实际导出，尤其检查版本适配的 `preview.ts`。

## 轮廓服从骨架

[actor.tsx](../motion/src/components/actor.tsx) 是外观适配层，输入已有 Rig，不重新算一遍人体运动。

`jointKnots(a,hinge,b)` 保留起点、关节和终点。肘膝的入柄、出柄共线等长，非退化情况下连接处一阶连续；控制柄按较短骨段限制，避免任意自动平滑产生大幅过冲。足底继续连接模型中的 ankle/toe，抓取仍跟实际 wrist。中心线是柔和轮廓，骨段约束约束的是内部 Rig，并非声明皮肤曲线的弧长恒定。

躯干用独立 Spline，头用圆形；远侧肢体降低亮度，避免重叠时失去轮廓。快动作先检查肩、髋、手脚的位置、先后和剪影，再微调控制柄。此实现是侧面 2D 表演，不包含完整人体解剖或软组织模拟。

## 几何与时间分开

[geometry.ts](../motion/src/geometry.ts) 的 `ballisticBezier(origin,velocity,g,seconds,map)` 把恒定重力的二次轨迹精确转换为三次 Bézier。它按真实已飞行秒数截取曲线，末点与身体同源；不是用若干折线近似，也不是靠路径形状猜身体的位置。

Motion Canvas 曲线的 `end` / `getPointAtPercentage` 使用路径长度语义。匀速画一条装饰线可以使用它们；`end(τ/T)` 通常不能让曲线头部和抛体同步，因为抛体速度会随时间改变。《留下弧线》每帧重新求截断曲线控制点，端点直接使用物理时间。

函数图、向量、圆与角色都通过同一个投影进入画面，注明轴向、单位和比例。数学几何需要精确关系时，优先解析构造；采样曲线要处理定义域、不连续点和误差，不把断点跨接成一条平滑线。

## 公式不是一张待替换图片

在场景生成器中按有意义的子式分组：

```tsx
const equation = createRef<Latex>();
view.add(<Latex ref={equation} fill="white"
  tex={String.raw`{{\Delta y}}{{=}}{{v_0\tau}}{{-}}{{\frac12 g\tau^2}}`} />);
yield* equation().tex(
  String.raw`{{2}}{{\Delta y}}{{=}}{{2}}{{v_0\tau}}{{-}}{{g\tau^2}}`, 1.1,
);
```

共同子式可保持视觉联系，分数、上下标与希腊字母使用矢量数学排版。检查相同字形的匹配、移动路线、相交与停顿；内置匹配不是数学推理器，也不保证重复符号的角色身份。被角色拿取的两个相同数字需要独立对象 ID / 节点，不能只靠字形自动匹配。

《留下弧线》的稳定状态依次为：

1. `Δy = v₀τ − ½gτ²`
2. `2Δy = 2v₀τ − gτ²`
3. `gτ² = 2v₀τ − 2Δy`
4. `g = 2(v₀τ − Δy)/τ²`

这些是 `equivalent_rewrite`，前提为 τ > 0；v₀ 是起跳后的初始竖直速度，Δy 从起跳时的髋部高度计，向上为正。物理式另假设恒定向下重力且忽略空气阻力。公式变形的中间轮廓不代表新的有效等式。模拟按假设生成数据，不能反过来当成对自然规律的实验发现或证明。

## 输出与验收

当前试片在 2560×1440 画布绘制，通过共享编码器一次 Lanczos 缩为 1280×720，再编码 H.264 / yuv420p；导出为 30 或 60 fps。网页缩放只是预览，不能代替观看编码后的线条和细小分数。SVG 节点经过最终视频编码后仍是像素。

至少检查：运动极值时的画幅、连续落地帧、曲线端点误差、骨架/抓点约束、公式稳定态与变形中间帧、重复拖帧、慢放、局部视频和失败时保护已有文件。数值误差、像素确定性、人工观片与完整听审分别记录。新主题要重写它自己的规则、接触与检查点。
