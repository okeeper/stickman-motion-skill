# 自动制作与交付

从剧本、表演试片、场景清单和素材进入制作；不要先决定使用内置渲染器，再降低动作要求以适应它。[表演与动作设计](performance-and-animation.md) 给出试片和检验方法；完整命令、清单和运行边界见 [自动制作运行时](autopilot-runtime.md)，视觉与声画设计见 [概念冒险视觉语言](concept-cinematic-style.md)。

1. 基于 [导演与剧本](concept-story-directing.md) 确定故事、知识假设、角色/对象身份、镜头和声音。只要文本或提示词时不用安装运行时。
2. 按实际表演任务检查本机或用户授权工具：逐帧绘制、骨骼/曲线动画、可编辑合成、声音剪辑与必要的生成工具是否能完成动作。内置渲染器没有自动骨长、接触约束或表演生成，不能作为复杂动作的默认质量保证；只在真实试片证明适合该镜时选用。在安装目录之外建工程；制作或取得有许可的角色、图形、音乐和声音。所有外部任务要检查状态和费用，失败或未知状态不盲目重复提交。
3. 按实际事件给每镜设计角色意图、重心、逐动作的关键姿态、接触点、对象前后状态、相机、符号叠层及声音。先制作最难的接触、反应表演或尺度转换，输出代表性短预览；正常速度看、逐帧检查接触并听审，再修到动作意图可读。预览可以先于后段素材完成。已获授权的任务继续完成，不强加预览审批；无法验证或无法做到时如实说明差距。
4. 渲染整片并核对逐镜缓存、时间线和实际编码文件；修改片段只重做受影响的图层或素材，并保留可复用的原文件。必要时生成字幕边车、联系表、项目和质量记录。
5. 分别记录科学/数学、画面连续性、动作、正常速度观片、完整听审与观众理解的实际状态。结构校验、成功解码、帧率和联系表都不能证明作品好看、动作可信或数学正确。

两片的视觉和剧情是分析参考：符号既可以作为字形被操作，也可以保留表达式含义；物理量可以通过轨迹、坐标和标注表现，尺度可以从角色局部行动扩大到环境或时空视角。新片必须明确哪些是可检验事实，哪些是空间隐喻、拟人或科幻设定。原片媒体不放进新作品。
