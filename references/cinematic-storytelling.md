# 电影式主角与因果剧本

用于写故事、改剧本、排动作分镜。目标是让观众把火柴人当成一个有意愿、会判断、会受伤也会调整的人。动作的趣味来自人物与处境的互动；知识机制提供解法、限制与后果。

完整例稿见 [《折返》](../examples/return-crossing.md)。它是待制作剧本，不是已经渲染的影片；90 秒、救援题材和双人配置都只是这个例子的选择。

## 先确定这个人

用一小段人物卡明确以下内容，不必写与当前故事无关的身世：

| 项目 | 要落实的内容 |
|---|---|
| 当下目标 | 他现在非做不可的具体事情；观众怎样看出成功或失败 |
| 在意的东西 | 他为什么愿意为目标冒险；可以是关系、职责、自尊、自由或好奇心 |
| 已有能力 | 能通过行动证明的本领，例如观察、协调、身手、耐心或空间判断 |
| 行动边界 | 当前知道什么、拿得到什么、身体能承受什么；是否受伤、负重或受限 |
| 个人习惯 | 一个能反复辨认的行为细节，例如先摸稳接触点，或先确认同伴再离开 |

主角可以谨慎、冲动、幽默或骄傲；选择要与当时的信息和性格相符。可靠能力需要在普通动作里先显露，高潮才能升级使用。普通人的判断力与超常的运动能力可以同时存在：能跳很远，也应该会估距离、选择落点、保护重要的人和物。

让压力、恐惧、习惯和关系参与判断。人物可以犹豫、逞强、错估，或明知自己会吃亏仍选择帮人；观众需要理解这份选择的来由，并看到后果。保留人的不完美，避免把每次行动都写成毫无情绪的最短路径计算。

成熟感通过具体动机、信息、取舍和后果建立。温和、明亮、轻喜剧的故事也能成立；不必统一成冷酷英雄、末日救援或高强度打斗。

## 用判断推动情节

一种可用的走向是“目标 → 观察与计划 → 执行 → 条件变化 → 调整 → 兑现与余波”。探索、对抗、合作等题材可以选择不同结构；不强制角色先犯错，也不要求每次成功后立刻再出事。

对会改变走向的选择，写明：

> 他已知道什么 → 此刻想保住什么 → 为什么选这个办法 → 哪个新事实使计划需要改变 → 结果与代价是什么。

“作者需要演示规则”不能作为角色的行动理由。合理失败可以来自信息不全、合理估计的误差、对手反制、时间或资源限制、能力边界；用具体原因支持。信息差必须保留在分镜里：观众知道但角色没看到的东西，不应算角色故意忽视。

| 易写弱的版本 | 更有判断力的写法 |
|---|---|
| 已看到方向箭头，仍反复按启动键制造错误 | 先读方向并正确设置；在载重、路线或控制权限改变后重新选择，保留相同规则 |
| 面对升序门牌，随意开门几次才开始二分 | 先确认排序后查询中点；比较结果直接决定路线，搜索成本影响能否完成目标 |
| 在同一个机关前连续失败，每次重新困惑 | 第一次接触提供信息；后续尝试改变假设、控制条件或用途，角色记得刚才发生的事 |
| 高潮突然出现新道具或新能力 | 提前以日常用途、一次代价较小的使用或明确空间关系建立，高潮换用途或组合 |
| 对手放弃有效招式，等主角完成花活 | 对手根据目标和所见信息调整；主角通过位置、时机、资源或取舍创造空隙 |

角色误判时，应当能补上一句“因为他当时看见了……，所以这样判断”。也可以直接展示熟练操作，不把所有知识都拍成第一次上课。

## 目标、冲突与回收

目标需要改变人物的处境。获取一个物件可以成立，但应让观众先知道它为何值得拿、拿到以后会改变什么；星形物、钥匙或发光球本身不自动构成动机。

主要阻碍应有可追踪的因果：环境持续变化、对手有自己的目标、两人的能力或意愿不一致，或完成目标需要付出资源和身体代价。事件不必越来越大，但可以让原来的解法越来越贵、迫使角色在两件在意的事之间选择。

反转应改变观众对既有信息的理解，或改变角色可采取的行动。建立过的机制可以在新的处境中获得新用途；不要在高潮才给世界添加一条恰好能解围的规则。风险如果早已明显，角色应先控制可控制的部分，残余风险才构成紧张。

结尾回收最初的目标，并留下行动的余波：身体还在恢复、关系发生变化、某种习惯被重新理解，或环境继续按既有规则运行。根据片型决定是否留悬念，不必每次举奖品或摆胜利姿势。

## 把“帅”落实到动作里

优先写清楚动作解决了什么问题，再设计它的观赏性。例如越过阻挡、接住正在离开的目标、借已有速度换向、在失衡中保护同伴、完成一次省力而准确的反制。

为重点动作补足这些信息即可，不必每个抬手都填表：

- **判断与机会**：角色看见什么，怎样创造或等到可执行的时机。
- **动作路线**：从哪里出发，依靠什么接触点，身体和目标各到哪里。
- **发力与结果**：预备、速度变化、接触、卸力、恢复；夸张部分对应什么能力。
- **人物含义**：这个动作表现谨慎、控制、恐惧、保护还是孤注一掷；结果怎样影响下一次行动。

动作可以很快，决策仍要看得见。先让观众读到目标和可用支撑，再加速执行。最有效的重音可能是一次准确的停、一次及时松手或很短的反应；不需要每个动作都翻转、慢放、拖影或震屏。

连续动作应相互接续：前一次落脚成为下一次发力点，前一次碰撞影响下一次姿态；有足够接触和主动用力时才能获得新的速度。空中随意改道、承重不变的单臂飞甩、没有目的的连续空翻，都要先解决运动因果。具体重量模型见 [重量与弹性](weighted-motion.md)。

## 无表情也能读懂他

把情绪写成对具体对象的行为，不只标注“他很愤怒”“他很酷”。同一种情绪可以有多种表演，也会因关系和处境改变。

| 内心状态 | 可供选择的身体行为 | 需要带出的后续行动 |
|---|---|---|
| 谨慎，但准备承担风险 | 先给落脚点少量压力；头朝目标，髋留在可退的位置 | 确认承重后才把全身重量移过去 |
| 看见同伴处境后决定留下 | 身体已经朝出口，离开的那只脚却收回；回头后才转髋 | 改变路线，把自己的位置让给同伴 |
| 受惊后重新控制自己 | 短促失衡，手先找支撑；站稳后停一拍，重新定位目标 | 后续行动更精确，不循环同一个惊讶姿势 |
| 压住怒气 | 想追击的起势被自己刹住，收回伸出去的手，转而处理更重要的事 | 观众看见他作了取舍，而非只是摆出愤怒轮廓 |
| 受伤仍在做判断 | 避免伤侧承重，换手、换支点，重新估计可达范围 | 路线和动作确实受影响，不能下一镜恢复全力 |
| 终于放松 | 手从紧握变松，肩部下沉，允许自己坐下或接受扶持 | 危险已经解除，给观众读到余波的时间 |

关键反应可遵循“注意转移 → 身体准备 → 执行 → 结果后的重新判断”，不把头、双臂和双腿同时切换成一个姿势。头部方向负责引导注意，肩髋关系和重心负责表明倾向，手与人的距离表明关系；只有角色需要时才增加动作。

双人表演要保留对方的回应。伸手是否被接受、位置是否被让出、谁先放下防备，都比两个角色各自播放一套姿势更能建立关系。声音可加强呼吸、迟疑和冲击，剧本不能依赖台词、表情贴图或情绪字幕才能被理解。

## 趣味来自具体的人

可以使用预期与结果的小落差、两个人对同一处境的不同反应、先前细节的回收，或完成险事后短暂放下姿态。幽默应与当时目标相容，不抹掉危险和代价，也不反复拿主角忘记规则、明显无能或同伴受伤当笑料。

例如一个习惯先照顾别人的主角，脱险后仍想伸手扶对方，伤侧动作刚开始便收住；同伴让出身旁的位置，他才接受一起休息。趣味在于观众认出了这个人的习惯和变化。该例不应成为每个故事固定的尾声。

## 写完后的自审

先用下面的问题找出具体薄弱段落，再修改，不用字数、镜头数或自动评分替代判断：

1. 不说知识点，能否清楚复述这个人想完成什么、为何在意？
2. 关键选择是否利用了角色已经知道的信息？如果有明显更简单的办法，故事有没有给出不采用它的可见理由？
3. 失败之后改变了什么？若去掉一次失败，剧情毫无变化，它可能只是重复演示。
4. 去掉“帅气、震撼、紧张、悲伤”等形容词后，动作、空间与关系是否仍可执行、可理解？
5. 高潮用到的物件、机制和能力是否提前出现？对手或环境是否为了让主角成功而突然失常？
6. 疲劳、受伤、负重与损失是否延续？帮助别人的选择是否真的影响了主角的行动？
7. 静音、遮掉情绪标签后，能否从行为读到主要的注意、意图、反应与关系变化？
8. 是否给关键结果和余波留下了可读时间？试做分镜后仍需正常速度审看。

文字检查只能确认设定与行为的自洽程度；肢体可读性、镜头节奏和“帅不帅”要用关键姿态、动态分镜与实际成片验证。
