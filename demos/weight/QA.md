# 重量与弹性研究：实际检查

检查日期：2026-10-23。对象：[weight-study.mp4](weight-study.mp4)，对应 0.3.0 的 TS 动作模型。原三支 Python 概念片不在本次动作质量结论内。

## 实际媒体与浏览器

- FFmpeg 全片解码通过；实际为 1280×720、60 fps、935 帧、15.583333 秒，H.264 / yuv420p。
- AAC 双声道、48 kHz；解码音频采样峰值约 −16.69 dBFS，无采样削波。AAC 解码尾部包含编码填充，解码长度约 15.595 秒；这不表示新增了一段画面。
- [导出记录](weight-study.json) 包含每段参数、事件与文件 SHA-256；[实际媒体检查](qa.json) 独立解码并核对技术事实。合成音频峰值与 AAC 解码峰值是两个不同指标。
- [浏览器检查](browser-checks.json) 覆盖预设、暂停、拖帧、速度、重置、参数重建、无效输入后的恢复、随机拖帧像素一致性、自托管字体、桌面及 390 px 手机宽度。没有页面脚本错误或外部运行时资源请求。
- 另实际导出了一次自定义参数的 30 fps 视频，用于验证 JSON 配置和第二种输出帧率；该临时测试产物不作为公开 demo 分发。

## 动作检查与证据

查看了 [全片关键帧](contact-sheet.jpg) 和 [大跳落地的连续抽帧](landing-contact-sheet.jpg)，并检查过三个预设的预备、离地、顶点、触地、压缩和恢复姿态。

连续抽帧呈现：着地前脚接近地面，着地后髋部继续下降、膝部弯曲，上身与手臂跟随，随后伸展。检查中发现并修正了空中展腿过早锁地、高重力时静态支撑超出腿长、二次回弹后未更新脚部支撑位置等问题。新模型以固定骨长和实际接触数据绘制，不能再靠曲线轮廓遮住脚踝断开。

8 项 TS 回归覆盖：

1. 飞行段重力加速度、顶点速度和机械能。
2. 蓄力、质量、起跳动能与势能的预算，以及非负地面反力。
3. 蹬伸、离地与首次触地的位移/速度连续性；着地速度不会清零。
4. 冲击后的能量耗散、较小回弹与最终恢复。
5. 每根肢体骨长、脚踝连接、脚底不穿地和连续承重时支撑点不滑动。
6. 任意拖帧及 30/60 fps 采样使用同一时间状态。
7. 非有限值、越界参数和做功不足的明确失败。
8. 72 组边界组合：64 组能完成跳跃并恢复，8 组做功不足被拒绝；完成的动作不出现不可达脚踝或中途截断回弹。

构建、浏览器检查、代码格式检查和原有 26 项 Python 回归通过。文档校验另外验证了 Web 文档断链的失败与修复路径。

## 尚未验证

这些结果证明的是列出的运动约束、交互和实际媒体规格。没有记录真人正常速度观片、主观音效听审或观众理解度测试；不能据此声称达到原片的表演水平。当前只有近侧面、平地单次跳跃及被动回弹，尚未覆盖翻滚、多处接触、复杂道具和完整肢体动力学。
