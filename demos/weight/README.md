# 04 · 身体有重量

**任务：** 让同一个火柴人完成自然跳跃、蓄力大跳，以及同样发力下更重的身体跳跃。通过蓄力、支撑、腾空和落地恢复，验证新的动作模型；不是数学概念短片。

![蓄力大跳预览](heroic-preview.gif)

[完整 60 fps MP4](weight-study.mp4) · [导出事实与参数](weight-study.json) · [关键帧](contact-sheet.jpg) · [实际检查记录](QA.md) · [网页工程与命令](../../web/README.md)

完整成片 **15.583 秒，1280×720，60 fps，935 帧**，含原创事件音效，无旁白和音乐。GIF 是 20 fps 的大跳摘录；判断速度和流畅度请看 MP4。

| 片段 | 质量 / 蓄力 / 发力 | 竖直起跳速度 | 相对离地点的上升高度 | 观察重点 |
|---|---|---|---|---|
| 0–5 s，自然跳跃 | 70 kg / 0.60 s / 0.65 | 2.57 m/s | 0.34 m | 适度下蹲、蹬伸、落地吸震 |
| 5–10.583 s，蓄力大跳 | 70 kg / 1.05 s / 1.10 | 5.62 m/s | 1.61 m | 更长蓄力、更快蹬伸、更大冲击及衰减回弹 |
| 10.583–15.583 s，更重的身体 | 105 kg / 0.60 s / 0.65 | 1.48 m/s | 0.11 m | 做功与第一段相同，质量更大，跳得更低 |

三段的相机在各自片段内固定，按动作范围适配缩放；比较定量高度以表中米数或网页数值为准，不跨片段直接比较像素高度。模型的艺术设定与物理简化见 [重量与弹性](../../references/weighted-motion.md)。

这些是 TS 动作研究的新产物。原有三支 36 秒概念故事仍使用 Python 引擎，并未被这段动作研究替换。更复杂的抓取、翻滚和跨障碍故事仍需要新的场景与接触状态设计。
