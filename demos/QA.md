# 三支探索 Demo 的实际验证记录

对应 **0.9.0 / 2026-10-26**，使用 Node.js 22.22、Motion Canvas 3.17.2、Playwright / Chromium 和 FFmpeg。三支故事重新制作，当前文件不再是 0.8.0 的短版。

## 实际编码文件

三支均经过 ffprobe 读帧统计与 FFmpeg 全部音视频解码，H.264 / yuv420p、1280×720 / 60 fps、48 kHz 双声道 AAC。以 2560×1440 绘制再 Lanczos 缩小；MP4 使用 faststart。

| 成片 | 时长 / 帧数 | 声音事件 | AAC 解码后峰值 |
|---|---|---|---|
| 《别追，等它回来》 | 75 秒 / 4500 帧 | 287 | −7.35 dBFS |
| 《谁在敲门》 | 85 秒 / 5100 帧 | 149 | −12.01 dBFS |
| 《世界的侧面》 | 90 秒 / 5400 帧 | 119 | −7.79 dBFS |

[媒体核验与 SHA-256](media-check.json)；每支同名 JSON 保存原始时间区间、完整事件、音源清单指纹和视频指纹。PCM 混音未削波，解码后的 AAC 为有限值、非静音。声音含 Kenney CC0 接触素材与自有程序合成，不使用参考视频音轨。555 是含音乐和滑动底声的事件总数，不等于 555 次人物动作。

## 数学与动作检查

[共享 TS 测试](../web/tests/series.test.mjs) 覆盖：

- 每 1/240 秒检查全片固定骨长、有限值、人物构图边界和局部连续性；对每个百分之一秒的左右极近时刻另查边界，避免只测单侧而漏掉条件分支跳变。乱序求值一致，无效时间失败。
- 骨长与逆向运动学的目标残差分开：[数值报告](review/numerical.json) 记录实际长度误差与 IK 残差。求解器为完全伸直的奇点保留 10⁻⁶ 米余量；这不是有意义的画面误差，也不是表演自然程度评分。
- 三次负号操作的设置立即变化，实际速度各经过 0.6 秒连续反转；关键手接触与移动落点一致，最终着台脚尖落在箭身高度。
- 二分查找对全部 16 个可存在目标正确保留候选，本片查询索引为 8、12、14、13；无序、重复、非有限值拒绝，缺失目标不误报匹配。原数组保持，目标地址在展开之后才出现。
- 四次复数旋转的归一化模长为 1，完成点为 i、−1、−i、1；角色攀移只改变握点半径。攀爬时双腕与实际握点一致。
- 腾空根部水平速度恒定、竖直加速度为 −9.81；飞行期间无脚步事件。无效跳跃预算、错误 CLI 参数和坏音频输入有失败检查。
- 新增敲击、滑动、转动、发现和音乐的局部 PCM 与整片同区间完全一致，延迟回应保持敲击身份；非法音符、声音身份及回声参数失败。

[浏览器检查](review/browser-checks.json) 每 0.5 秒取样，共 500 帧，并检查关键帧逆序读取、默认 1×、点击后声音就绪、390 px 布局和本地资源请求。它不等于对全部 15000 帧进行主观逐帧审看。完整输出帧由渲染器计数并在实际 MP4 中再次读帧核验。

本轮 Python 33 项、共享 TS 26 项、Motion Canvas 6 项测试通过；构建通过。媒体工具会拒绝缺失或短版输入，已有预览受到保护。没有据本机结果声称远端 CI 已通过。

## 播放、构建与复用

[机器播放记录](review/playback.json)：Chromium 对实际 MP4 以 1×、未静音状态播放到结束，核验音频解码和视频尺寸；丢帧数按实际记录，不把并发机器播放等同于人工观片或听审。

[生产构建](review/production.json) 验证三支静态构建页、后段求帧与导航。[独立工程](review/portable.json) 验证复制后单独安装依赖、准备声音、构建，并实际导出《谁在敲门》67.5–68.2 秒的 42 帧有声片段；临时工程随后移除。通用剪辑产物见 [合集说明](tooling/README.md)。

## 仍需评价的部分

已完成文本与规则自审、数值约束、关键帧和连续抽帧查看、完整机器解码与播放。**未完成主观完整观片、完整听审及观众静音理解度测试。** 长段观察的节奏、悬挂的自然程度、敲击通路是否一次看懂，仍应通过实际观看反馈判断。峰值、骨长和帧率不能证明达到原参考作品的水平。

三片是手工编排的单人侧视动画；悬挂、攀爬、翻身和跌滚使用固定骨长与支撑约束，不是完整人体动力学或任意地形碰撞。空间通口属于故事约定；算法、复数乘法和物理建模的假设见 [生产规格](PRODUCTION.md) 与规则卡。
