# 三支重拍 Demo 的实际验证记录

本记录对应 0.8.0 的 TypeScript / Motion Canvas 成片，替代旧版 36 秒案例的当前交付记录。环境为 Node.js 22.22、Motion Canvas 3.17.2、Playwright 1.64.1 / Chromium、Python 3.10 与 FFmpeg 7.1.1。数值检查、画面检查和听感评价分别记录。

## 编码后的实际视频

三支均经过 ffprobe 读帧统计及 FFmpeg 全部音视频解码，H.264 / yuv420p、1280×720 / 60 fps、48 kHz 双声道 AAC；画面采用两倍尺寸绘制后缩小。

| 成片 | 时长 / 帧数 | 声音事件 | 解码后峰值 |
|---|---|---|---|
| 《逆向通行》 | 14 秒 / 840 帧 | 24 | −7.26 dBFS |
| 《最后一扇》 | 18 秒 / 1080 帧 | 37 | −9.52 dBFS |
| 《转过死角》 | 21 秒 / 1260 帧 | 39 | −7.27 dBFS |

[完整媒体核验与 SHA-256](media-check.json)。每支同名导出 JSON 保存原时间区间、采样、声音源清单指纹和视频指纹。混音 PCM 未削波；解码后音轨为有限值且非静音。AAC 有不足 22 ms 的尾部填充，视频长度与预期一致。17 份 Kenney CC0 素材以本地校验缓存复用，仓库不包含下载的声音源文件或原参考视频。

## 画面检查与本轮修正

查看了从最终编码 MP4 生成的三张关键帧图，每张 12 帧：

- [《逆向通行》关键帧](posters/negative-ride-contact-sheet.jpg)：补充开场能看见左侧出口的远景；区分命令 `u` 和实际 `v`；左岸限位制动后，人物离车跑向出口。
- [《最后一扇》关键帧](posters/binary-search-contact-sheet.jpg)：比较结果在被查询候选暂时变暗前保留阅读窗口，移开有序性标记；升降台加宽以承接双脚，钥匙插入后解除携带手势。
- [《转过死角》关键帧](posters/complex-rotation-contact-sheet.jpg)：把完成等式移到圆内以避开人物；最终 `i⁴ = 1` 延后至上一等式消退后显示，避免叠字。

还查看了最终 MP4 的连续时刻，下面均为**本项目原创成片的诊断裁切**，图中追踪人物居中，仅用于查看姿态：

- [登台跳跃](review/negative-ride/jump-sequence.jpg)：1.20–2.30 秒，每 0.10 秒一帧，包含预备、离地、收腿和承重。
- [伏身过梁](review/negative-ride/beam-sequence.jpg)：5.95–7.60 秒，每 0.15 秒一帧，包含提前护头、通过和起身。

- [第一段旋转](review/complex-rotation/orbit-sequence.jpg)：2.65–4.65 秒，12 帧，检查身体倾身、直立方向和平台相对接触。

新版修正了腾空至落地时脚尖朝向突变、收步时脚尖角度硬切，以及不同步态落脚时身体高度重置。站稳后保留支撑锚点，动作交接短暂用关节角连接；不宣称交接阶段也始终双脚锁死。

## 数学与动作自动检查

[TS 行为测试](../web/tests/series.test.mjs) 单独核验：

- 每 1/240 秒检查全片固定骨长、有限值、人物画面边界；对相邻极近时刻检查姿态硬跳变，乱序求状态一致。
- 负数操作在 3.0 秒改变 `u`，电机在 3.0–3.8 秒连续制动、过零并反转；8.0–8.8 秒限位制动是另一条设备规则。伏身期间头部圆形边界避开低梁。
- 二分查找的全部 16 个可存在目标都不被错误排除，中点向下取整、至多五次查询；本片为索引 8、12、14、13。无序、重复、非有限值被拒绝，缺失目标不误报匹配。原数组及索引位置保留。
- 复数归一化模长为 1，完成四次乘以 i 的精确停靠点分别是 i、−1、−i、1，方向为逆时针；连续展示期间平台的有效重力为正。
- 腾空根部的水平速度恒定、竖直加速度为 −9.81，移动源速度参与蹬离速度预算；飞行期间没有脚步事件。
- 无效时间、超出跳跃预算与错误导出参数明确失败；已有成片受到保护。

[浏览器逐帧结果](review/browser-checks.json) 覆盖全部 3180 个输出帧，最大骨长数值误差小于 1.8×10⁻¹⁵ 个世界距离单位；人物边界、确定性拖帧、默认 1×、点击后的声音就绪、390 px 页面布局及仅本地资源加载均通过。该数值不衡量表演自然程度。

本机回归：Python 33 项、共享 TS 25 项、Motion Canvas 5 项自动测试通过；两个 TS 工程的格式与构建、原图形试片和《断点》的浏览器回归通过。CI 已加入三片浏览器检查，本页不据此宣称远端 CI 已运行成功。

## 完整播放与独立工程

[实际 MP4 自动播放记录](review/playback.json)：Chromium 以 1×、未静音完整播放三支，报告 840 / 1080 / 1260 帧，丢帧均为 0，音频有实际解码，播放到结束无错误。这是机器播放检查，不是人工观片或听审。

[生产构建检查](review/production.json)：三支静态构建页面均能求帧、切换短片，无页面错误。[独立工程检查](review/portable.json)：复制到临时目录后独立 `npm ci`、素材缓存校验和构建成功，二分片 10.5–11.2 秒实际导出 42 帧并包含 AAC；验证后移除临时工程。

详细解码、音轨、均匀采样图分别见 [反向片](review/negative-ride/QA.md)、[二分片](review/binary-search/QA.md)、[复数片](review/complex-rotation/QA.md)。[52.4 秒合集](tooling/README.md) 同步按正常速度重建，复用了既有剪辑、缓存、软字幕与交付工具。

## 仍未完成的评价

已完成文本自审、模型测试、关键帧和连续抽帧查看、自动正常速度播放；没有把主观完整观片、完整听审或观众静音理解度测试标记为完成。峰值、帧率和坐标连续不保证音色、情绪或动作达到参考作品水平。

三片是固定关卡的手工编排侧视动画。它们没有通用人体动力学、任意地形碰撞或任意提示词生成；二分故事只表演目标存在且值唯一的情况，复数故事只表演单位圆上的乘以 i。新题材需要重新验证剧情、支撑、数学边界与声音。
