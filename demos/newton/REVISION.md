# 《怎么又是这里》：动作与互动修订

[新版有声视频](newton-v2.mp4) · [旧版](newton.mp4) · [新版编码后关键帧](../posters/newton-v2-contact-sheet.jpg) · [逐段数学推导](../../examples/newton-guide.md)

新版仍以 f(x)=x³−2x+2、0↔1 的牛顿二周期、从 −2 出发的收敛为知识线；保留旧片，方便对照。这次重点重排直接影响人物体验的场面，而非声称整片已成为逐帧手绘动画。

| 时间 | 旧版问题 | 新版具体处理 |
| --- | --- | --- |
| 0–2.3 秒 | 人物已经站在白点上，观众不知道为什么注意它。 | 小黄人沿可见支撑面走近白点，停步、低头；脚步事件来自实际步态。 |
| 2.3–4.6 秒 | 长时间维持蹲姿，难以看出尝试和回应。 | 下蹲、第一次碰线，短线在触碰之后伸缩；主角退身观察。接触和对象反馈分别有声音事件。 |
| 5.9–10 秒 | 手在脚边，长线、轴与曲线按时间出现，联系不清。 | 再次俯身，指尖沿短线拉动，线端与手共用坐标；松手后短线延长，再引出坐标轴和逐步显现的曲线。 |
| 13.75–15.8 秒 | 到达另一边后人物等待，缺少关系变化。 | 站稳后蹲下，触碰同一个载点，再起身观察；对象的下一次移动仍由原规则决定。 |
| 18.55–23.2 秒 | 回到起点后又长时间保持同一姿态。 | 先摸原处、抽身回看，再低头二次确认并留下刻痕；两个接触各有声音。 |
| 24.7–27.7 秒 | 短线片段看似突然出现，着地后转入翻滚时身体压缩不明显。 | 先将可见片段叠在已有切线上；起跳时从该处脱离，切线短暂留下缺口并恢复。落地接续压缩，再进入护头翻滚。碎片与切线身份是视觉隐喻，不改变牛顿映射。 |
| 48.8–52.9 秒 | 人物持杆几秒不动，试探过程难读。 | 身体换重心、收回杆尖，再次探触。标签在首次探触后出现；杆尖、手和可达范围同帧检查。 |
| 全片 | 角色太小，动作意图不易辨认。 | 探索和反应时收紧镜头，保留需要看清路径关系的宽景。主角改用当前 skill 的小黄色系。 |

新版增强了已有故事里的动作、接触和因果；探索左侧、改变初始值、重新搭乘的总体结构沿用旧版，并非重新构思的全新剧情。许多动作仍由二维骨架与约束姿态手工编排，缺少参考片中复杂、富于变化的手绘表演。看不到的普通观众是否理解剧情，也需要实际观众测试。

## 数学与物体边界

人物探索的那条曲线与切线仍由原模型计算，线条的延长、载人的小托和碎片自恢复是故事约定。0 和 1 的往返是求值；拖动起点时停止求值，放开后从 −2 开始迭代；这不是把函数改写成新函数。竖直轴向映射与载人小托是空间隐喻。有限次计算得到近似根，并非精确数值。

## 工程

- [表演修订模型](../../web/src/newton/refinement.ts)：动作节拍、接触反馈、镜头、落地压缩、声音事件；继续调用 [原牛顿模型](../../web/src/newton/model.ts)。
- [修订场景](../../motion/src/scenes/newton-v2.tsx)：短线、切线缺口、角色和相机呈现。
- [修订测试](../../web/tests/newton-refinement.test.mjs)：指尖与线端、触碰后的反馈、片段分离、落地压缩、杆尖和输入点接触，以及动作边界连续性。

```sh
python scripts/init_web.py output/my-newton-v2 --scene newton-v2
npm --prefix output/my-newton-v2/motion ci
npm --prefix output/my-newton-v2/motion run prepare:audio
npm --prefix output/my-newton-v2/motion run dev
# 打开 /newton-v2.html
```

在仓库 `motion/` 中运行 `npm run render -- --scene newton-v2`，默认输出 `demos/newton/newton-v2.mp4`；用 `--from`、`--to`、`--out` 试做片段。对应的编码记录、媒体检查和实际审看边界见 [新版 QA](QA-v2.md)。
