# 三支探索短片的实际制作规格

本文对应 **0.9.0 成片**。《别追，等它回来》75 秒、《谁在敲门》85 秒、《世界的侧面》90 秒，均为 720p / 60 fps、有声、无台词。前期设计见 [探索剧本](../examples/demo-redesign.md)，以下为实现后的实际时刻。

延续参考片的极简黑场、白色可操作对象、橙色主角、触碰与反馈，以及执行和判断之间的节奏变化；故事、矢量画面和声音独立制作。先让角色接触陌生事物，再出现可读规则。没有预先布置出口、奖励、电芯或解释面板。

## 《别追，等它回来》

一支箭头擦着脚边滑过。他跟上去，伸手扑空，发现尾部拨片；第一次操作把自己带倒。恢复后跟着箭头试第二次，确认反向需要时间。他短跳上箭身、带速跳离，跑到前侧等它靠近。最后压低身体起跳、空中拨片、释放，箭头反向回来接住他。结尾揉手腕，保留第一次失衡的代价。

| 时间 | 可见因果与表演 | 声音 |
|---|---|---|
| 0–13.2 | 看、跟随、伸手差一点、观察尾部、弯身触碰 | 落脚、低滑动底声、手接触 |
| 13.2–23.2 | 反向指令生效，惯性让身体继续向前；护身滚开、坐低检查手腕、起身 | 拨片、反转气流、扶地、身体触地、布料、呼气 |
| 23.2–40 | 追上确认；36.4 秒第二次操作，看完减速、过零、反向 | 跑步、抓握、机关与短音乐句 |
| 40–53.2 | 跟进，43.24 秒起跳登箭，49.24 秒带速跳离，再跑到前侧 | 发力、落地、接跑 |
| 53.2–61.06 | 比对路线和距离，等待靠近，再短蓄力 | 音乐逐步密集，发力前留空 |
| 61.06–61.92 | 起跳；61.14 秒手接触拨片；释放后按重力下落，与返向箭身会合 | 鞋底抓地、掠空、拨片、落地 |
| 61.92–75 | 压缩吸震、恢复，检查手腕后继续前行 | 承重、收步、呼吸和稀疏尾音 |

数学：`u → −u` 是方向设置求值，`u=±2`；每个设置单位映射为 0.45 米/秒的电机目标速度。实际 `v` 在每次操作后的 0.6 秒内连续反转，并经过零。电机提供力，负号不直接提供物理力。腾空根部遵守 `x=x₀+vₓt`、`y=y₀+vᵧt−gt²/2`，`g=9.81 m/s²`；箭头不会吸附空中的身体。详见 [规则卡](../examples/negative-ride.yaml)。

## 《谁在敲门》

小白框被敲两下后，暗处响起同样节奏。他贴近听、检查接缝，把折叠外壳拉开，露出有序通口；盖板合拢后，才从手持薄框背面发现地址 63。他依次查询中点，读反馈再决定移动方向。找到 63 后没有结束：手探入通口，竟从左手所持的框里伸出。动指、敲框与同节奏回响，说明开场的声音来自同一空间通路。

| 时间 | 行动与信息 |
|---|---|
| 0–10.8 | 靠近、5.00/5.28 秒敲击、延迟回应、贴近听与拉接缝 |
| 10.8–18.4 | 16 个通口依次展开；地址升序短暂可见，然后盖板合拢 |
| 18.4–24.2 | 提起薄框、翻看；22.4 秒以后才显出地址 63 |
| 28.1 | 查索引 8，得到 31；保留候选 9–16 |
| 38.0 | 查索引 12，得到 55；保留候选 13–16 |
| 45.2 | 查索引 14，得到 70；收步折返，只剩 13 |
| 50.8 | 查索引 13，得到 63；匹配，但声音来源仍未解释 |
| 57.2–68 | 再敲、打开内盖、伸手；另一端在手持框里出现 |
| 68–85 | 小幅惊讶、动指确认、77.2/77.48 秒敲击和回响、抽手张望 |

数学：16 个值严格升序且唯一，目标存在。查询中点向下取整，使用闭区间；排除候选只改变显示亮度，不删除或重排原数组。查询次数与人物跑动时间分开。空间通口和声音传播是故事约定，二分查找不创造传送门，也不涉及穿越时间。详见 [规则卡](../examples/binary-search.yaml)。

声音中每对原敲击与回应共享声音身份，延迟 0.58 秒并降低强度；没有把同一个提示音用于脚步、机械展开和敲框。

## 《世界的侧面》

窄台边只有白杆的一端和 `1`。他轻触、掀开夹片，看见 `i`。扣回使白杆绕远处支点转动，人被意外带离落脚处，抓紧、找支撑、看回原地。确认第二次四分之一转后，横向攀向支点，把夹片带到近处；后两次旋转时抱紧收腿。回到右侧后翻身上杆、接跑、跳回原台，坐低舒展手指。圆由四段真实轨迹累计出现。

| 时间 | 动作与数学结果 |
|---|---|
| 0–12.6 | 靠近、触摸、打开夹片；整体结构尚未亮起 |
| 12.6–13.9 | 第一次旋转；意外离地，双手抓紧，完成后 `1 × i = i` |
| 14–31.2 | 试着用脚找支撑、换握、看原台，主动再次操作 |
| 31.2–32.5 | 第二次旋转，完成后 `i × i = −1` |
| 39–49.5 | 12 次交替换手，向支点内移；杆长不变，变化的是人的抓握半径 |
| 54.7–56 | 第三次旋转，收腿靠近支点，完成后 `(−1) × i = −i` |
| 56–73 | 恢复、观察三段轨迹、看起点与准备下一次 |
| 73–74.3 | 第四次旋转，完成后 `(−i) × i = 1` |
| 74.3–78.3 | 双手发力翻上杆、脚承重、释放手、接跑、跨隙回台 |
| 79–90 | 坐低呼吸、活动手指、起身张望；最后显示 `i⁴ = 1` |

数学：原点固定，右为实轴正向，上为虚轴正向。被乘对象是归一化复数向量端点，`|z|=1`；画面单位半径映射为 3.984 米。乘 `i` 表示逆时针 90° 且模长不变。动画中间角度是连续呈现，不逐帧声称已完成离散乘法。角色攀移不改变向量模长；人体与机关的支撑、主动驱动属于场景约定。详见 [规则卡](../examples/complex-rotation.yaml)。

## 可复用模块与边界

- [model.ts](../web/src/series/model.ts)：确定性时间、相机、片段衔接、事件与原创稀疏音乐。
- [acting.ts](../web/src/series/acting.ts)：固定骨长的站、看、伸手、坐、滚、悬挂、双脚支撑与姿态连接。
- [negative.ts](../web/src/series/negative.ts)、[binary.ts](../web/src/series/binary.ts)、[complex.ts](../web/src/series/complex.ts)：各自的规则、行动、抓点、声音时刻。
- [motion.ts](../web/src/series/motion.ts)：双向跑步、短预备跳跃、移动载体及支撑转移。
- [series.tsx](../motion/src/scenes/series.tsx)：矢量场景、顺次展开、轨迹积累、空间通口遮挡。
- [foley.mjs](../web/src/foley.mjs)：共享拟音、可复现敲击回应、原创程序音乐和局部导出的音尾。

这是编排的侧视骨架动画。跳跃使用解析重力，抓点由逆向运动学求解；悬挂、攀爬、翻身、跌滚和恢复为手工设计的姿态与支撑约束，不是通用人体动力学、任意碰撞求解或自动编剧。检查实况与未完成的主观评价见 [QA](QA.md)。
