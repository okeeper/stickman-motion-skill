# 三支代表性 Demo 的制作规格

统一配置：1280×720、30 fps、每支 36 秒、无台词、原创程序合成声音；深色空间、琥珀色角色、薄白线结构、薄荷色有效反馈、珊瑚色错误反馈。角色和道具为代码绘制的矢量形状，字体单独保留许可。

## 01 — Negative Ride / 反向才到达

任务：角色要跨越缺口，取回左侧星形物；可操作的运载车最初朝右。

概念：对一维有符号的下一次运行速度应用乘以 -1；连续两次反向恢复原值。只有在启动后车辆才运行，停车时面板表示下一次运行的设置值。

| 时间 | 事件 | 可见因果 |
|---|---|---|
| 0–4.8 | 查看缺口与目标，走向启动按钮 | 需要借助运载车跨越缺口 |
| 4.8–8.8 | 错误方向试运行，角色追赶，车辆在轨道限位前停下 | +3 向右，未到达左侧目标 |
| 9–14 | 触碰 ×(-1)，箭头反向；停顿观察 | +3×(-1)=-3 |
| 14–19 | 再试一次，又指向右；困惑后理解 | -3×(-1)=+3 |
| 19–23 | 主动再反向，跳上车并启动 | 复用刚学到的机制 |
| 23–31 | 向左行驶、越过缺口，跳下拿到目标 | 规则解决开头的目标 |
| 31–36 | 角色举起星形物，车辆安静停靠 | 以行动完成收束 |

隐喻边界：符号开关控制设备属于动画约定，乘法本身不直接给真实物体施加力；轨道限位为设备行为。

## 02 — Halve the Search / 只留下一半

任务：在 16 扇值升序排列的门中找到值为 63 的门。底部显示固定索引，门面初始隐藏值，触碰后揭晓；钥匙标明目标 63。

概念：对有序、唯一整数数组做二分查找。按下取整的中点索引查询：8、12、14、13，对应值为 31、55、70、63；比较后排除已确定不包含目标的一侧。完整数组见 [规则卡](../examples/binary-search.yaml)。

| 时间 | 事件 | 可见因果 |
|---|---|---|
| 0–7.5 | 随便尝试第 3 扇门；打不开；看钥匙、思考 | 8≠63；建立目标 |
| 7.5–15 | 走到索引 8 并比较，1–8 号门退场 | 31<63，保留 9–16 |
| 15–21 | 查询索引 12，9–12 号门退场 | 55<63，保留 13–16 |
| 21–26.5 | 查询索引 14，14–16 号门退场 | 70>63，保留 13 |
| 26.5–32 | 返回 13 号门，匹配钥匙，打开并取得星形物 | 63=63 |
| 32–36 | 目标取出，角色展示结果 | 由漫无目的尝试转为有依据的操作 |

隐喻边界：门退场表达候选排除，不是算法会删除原数组。最初尝试 3 号门不计入后续二分查询序列。

## 03 — A Quarter Turn / 四分之一圈

任务：从复平面的 1 出发，取回 -1 附近的星形物并带回起点。

概念：单位圆上的复数乘以 i，对应逆时针转 90°；四次相乘依次得到 i、-1、-i、1。角色乘坐的载台承载复数位置，角色的身体姿态不参与复数计算。

| 时间 | 事件 | 可见因果 |
|---|---|---|
| 0–5.6 | 够不到对侧目标，观察 ×i 按钮并触碰 | 建立可操作物与目标 |
| 5.6–10.4 | 第一转，从 1 到 i，结果停留 | 1×i=i |
| 10.4–17 | 第二转到 -1，伸手拿取目标 | i×i=-1 |
| 17–24.6 | 带着目标继续第三转到 -i | (-1)×i=-i |
| 24.6–31 | 第四转返回 1，跳到起点平台并放下目标 | (-i)×i=1 |
| 31–36 | 留下完整轨迹和 i⁴=1，角色完成送达动作 | 四次复用形成闭环 |

隐喻边界：转动过程是离散乘法之间的展示插值，不将中间角度误标为已完成的乘以 i。

## 制作与检查

先输出关键帧和连续动作预览，再渲染完整视频。检查接触点、跨越轨迹、公式状态、候选范围、复平面方向、同一时刻重渲染结果、音轨峰值、视频时长和编码。抽帧与自动检查的范围写进实际 QA 报告。
