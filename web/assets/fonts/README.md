# Motion Sans 字符子集

motion-sans.ttf 是 Google Fonts CSS API 为本页面文字返回的 Noto Sans SC 字符子集，按 SIL OFL 1.1 分发，完整许可见 [OFL.txt](OFL.txt)。来源：[Google Fonts Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC)，[原字体许可](https://github.com/google/fonts/blob/main/ofl/notosanssc/OFL.txt)。

只包含当前界面、画面标签和常用 ASCII 字符；新增故事文本时应扩大子集或换成具有完整所需字符的 OFL 字体。字体保存在工程中，预览与离线渲染不向字体服务发请求。未使用 anything2explainer 内的字体文件。
