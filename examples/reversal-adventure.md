# 《借势》：方向因子进入行动

主题：实数方向设置乘以 −1；用一段无台词动作展示符号操作与身体后果。成片 28 秒、1280×720、60 fps，默认不烧录解释字幕。实现见 [model.ts](../web/src/adventure/model.ts)，[实际视频与检查](../demos/adventure/README.md)。

## 人物与空间

一个向右行进的旅人遇到缺口。左岸到 x=3.58，右岸从 x=9.75 开始，中间有沿短轨道移动、最初向左的白色支撑，平台半宽 0.84。轨道末端在右岸之前，平台无法直接把人送上岸。平台上的乘法槽缺一个因子，岸边有可拿取的 −1。

主角观察平台的来向，拿上因子，靠近左岸边缘，先登台再改变方向。平台右行后，他在末端制动之前借已有速度跳向右岸。提前起跳利用已知身体能力和载体速度；不是看到缺口便盲跳。结尾先恢复、回望，再继续前行。

这是一位熟悉符号装置的旅人。短片没有展开“他如何首次学会乘法”，也没有把拿到物件本身当作奖品或人物动机。若改成面向第一次学习负数的教学任务，应增加规则发现和验证，重新安排片长与动作，不冒充本片已经讲完该教学过程。

## 规则卡

| 项目 | 约定 |
|---|---|
| 数学命题 | 对方向设置 d∈{−1,+1}，乘以 −1 得 d′=−d，大小保持、方向反转 |
| 表达式编辑 | 实体因子 token-minus-one 被装入乘法槽 slot-multiply |
| 求值 | 12.00 s，原设置 d=−1，求得 d′=(−1)×(−1)=+1 |
| 空间隐喻 | 电机按新的方向设置制动、反向加速；实际速度 v(t) 与 d 分开 |
| 物理假设 | 固定近侧面、同高支撑、向上为正、局部 g=9.81 m/s²；角色为有效质量模型 |
| 能力边界 | 跳跃的相对发力在预算内；离开平台继承其水平速度；脚与手有明确接触 |
| 回收 | 携带的因子用于改变支撑方向；平台给予的速度成为离台跳跃的初速度组成 |
| 非证明部分 | 符号可抓取、乘法槽能控制平台是世界约定；平台不是数学运算的现实装置 |

方向设置在触发时改变，实际速度用有限时长的连续制动与加速响应；公式不会把仍在左行的平台谎标为实际速度为正。画面箭头表示所设方向，细轨道表示移动约束。惯性通过身体姿态和接触继续显现。

## 分镜与声音

| 时间 | 选择、行为与身体状态 | 镜头与声音 |
|---|---|---|
| 0–2.8 s | 先看缺口、对岸和来向；注意转到可携带的因子 | 全景建立空间，随后靠近拿取位置；稀疏音乐 |
| 2.8–4.4 s | 伸手、接触、拿走 −1；腕部与符号绑定 | 保持可读近景；实际抓取时一个轻接触声 |
| 4.4–5.8 s | 带着因子靠近起跳位置 | 承重脚固定，摆动脚前移；脚步来自实际着地事件 |
| 5.8–8.87 s | 稳住、蓄力、蹬伸，带着因子腾空并登上左行平台 | 镜头放开，保住起跳点、平台与落点；起跳摩擦、落地低频与短尾 |
| 8.87–11.2 s | 落地吸震、水平卸力，承重转交给移动支撑 | 肢体恢复，不把下落和水平速度清零；音乐回落 |
| 11.2–12 s | 手把携带的因子送入平台槽 | 相机靠近操作，手与槽的抓点重合 |
| 12–13.4 s | d′=−d=+1；平台先制动再右行，主角承受加速并调整上身 | 规则声与电机声分开；短几何反馈从槽位展开后退去 |
| 13.4–17.31 s | 确认右岸与轨道末端，保持承重，蓄力准备离台 | 相机逐渐放开，强度为下一次执行建立准备 |
| 17.31–18.47 s | 继承载体速度，越过剩余空隙 | 腾空使用原速时间和解析重力；动作景别保住平台与右岸 |
| 18.47–23 s | 落地、卸力、恢复；站稳之后回看 | 接触重音后给身体恢复与较安静的余波 |
| 23–28 s | 继续走向前方 | 轻脚步，拉远回看整个空间；没有奖品或强制庆祝 |

## 实现与待验证边界

抓取、平台变向、承重、跳跃与声音均来自同一时间模型。两次跳跃复用同一个竖直重量模型，水平速度根据不同支撑求解；第二次含平台原有速度。相机是独立轨道，控件与诊断不会进入视频。

本片为单机制原型，没有实现对手、自主符号角色、大规模数学空间生长、翻滚或双人动作。是否能够静音理解人物意图、是否有足够“帅感”以及音色是否令人信服，都需要实际观看或观众检查；自动约束通过不替代这些判断。
