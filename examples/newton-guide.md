# 《怎么又是这里》：牛顿迭代的切线向导

82 秒，无台词，橙色主角、白色知识对象、黑色空间。实际成片、缩略图和检查记录见 [交付目录](../demos/newton/README.md)。可编辑规则与动作在 [TS 模型](../web/src/newton/model.ts)，画面在 [Motion Canvas 场景](../motion/src/scenes/newton.tsx)。

## 构思：同一个对象，三次理解

一个站在短线上、刚找回平衡的人，摸索出一条可以载着他移动的切线。他把它当作向导。第二次落回原位时，他先怀疑自己；认出脚边的刻痕后，他按住落点，发现向导短暂停了一下。他试图靠跳跃离开循环，却摔到下方。向导没有追他，仍在按自己的规则往返。

地上有他刚才扯下的一段短线。他捡起它，够住上方的轴，沿轴向左探索。曲线的另一支从画外出现。他用短线触到那一支，试出一个不同的切线落点。接下来他跑回原位，等向导落在零处，钩住真正的输入点，将起点拖到 −2。放开后，他需要主动蓄力、跳上新位置；这次，切线逐步缩短，终于不再把他送回右侧。最后，他把短线放回向导的一段延长线上，轻碰同一个点，身体才放松。

物件身份始终相连：脚边短线 → 切线向导 → 被扯下的片段 → 探路工具 → 钩住原输入的工具 → 归还的短线。没有临时出现的出口、钥匙、字幕任务或怪物。向导的“执拗”来自牛顿映射的二周期。

这是按 [参考片专用提示词 A/B](../references/reference-screenwriting-prompts.md) 制作的新题材实做。借鉴触觉操作、对象主动回应和旧经验进入后段动作的组织方式；没有使用参考片的画面、音轨或原情节。

## 数学机制与推导

设 f(x)=x³−2x+2，采用实数运算，f′(x)=3x²−2。牛顿更新需要当前导数非零。

在 xₙ 处，切线为

```text
y = f(xₙ) + f′(xₙ)(x − xₙ)
```

令 y=0，解得

```text
xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ)
```

这一步是切线与横轴交点的精确求解；用它近似曲线的根则属于迭代方法。不能将切线与曲线等同，也不能把求值过程写成整串始终相等的公式。

### 为什么会回到原处

f(0)=2，f′(0)=−2，所以 N(0)=0−2/(−2)=1。
f(1)=1，f′(1)=1，所以 N(1)=1−1/1=0。

因此从 x₀=0 出发，严格得到 0→1→0→1…；这不是“速度慢”，而是不会收敛到根的二周期。角色掉下支撑并不改变这个序列。

### 为什么从 −2 开始能走出去

| n | xₙ | f(xₙ) |
| --- | --- | --- |
| 0 | −2 | −2 |
| 1 | −1.8 | −0.232 |
| 2 | −1.7699481865 | 约 −0.00484966 |
| 3 | −1.7692926629 | 约 −0.0000022814 |
| 4（片外核对） | −1.7692923542 | 数值舍入精度附近 |

f(−2)<0，f(−1)>0，连续性保证存在 α∈(−2,−1) 使 f(α)=0。在 [−2,−1] 内，f′(x)≥1>0，函数严格递增，故该区间内只有一个根；f″(x)=6x<0，曲线凹向下。

对 −2≤x<α，f(x)<0，故 N(x)>x。凹性给出

```text
0 = f(α) ≤ f(x) + f′(x)(α−x)
→ N(x) = x − f(x)/f′(x) ≤ α
```

所以 x₀=−2 开始的序列递增且以 α 为上界，存在极限 L。N 在这一区间连续、导数分母不为零，取极限得 L=N(L)，即 f(L)=0。由唯一性，L=α。这证明本片选定的新起点可以收敛；不意味着任意函数、任意初始值都会收敛。

该二周期与牛顿法限制可对照 [OpenStax《Calculus Volume 1》4.9](https://openstax.org/books/calculus-volume-1/pages/4-9-newtons-method)。影片实际停在第 3 次更新，显示近似符号，没有宣称有限次精确求出无理根。

## 实现语义与物理边界

- `evaluate`：真实计算 N(xₙ)，先竖直映射到曲线，再沿当前切线抵达下一横轴交点。运动采用平滑调度；中间的载点不是额外迭代。
- `expression_edit`：按住输入并将 x₀ 从 0 拖到 −2。拖动时暂停求值，避免在途经 f′(x)=0 的位置调用牛顿法。放开才提交新起点。
- `equivalent_rewrite`：只用于上述切线方程推导，电影没有让角色改写 f 或把不等价表达式串成等式。
- `spatial_metaphor`：白色导线、载点、小横托、杆尖接触和左右探索是知识的空间表达；它们不证明公式。屏幕坐标是 X=3x、Y=0.5f(x)，图像是精确三次 Bézier，切线也按这一缩放转换。横轴 y=0 悬在实体地面 Y=−2 上方，两者并非同一支撑。

向导是提供支撑力的虚构主动载体，角色脚下有水平小托；不是说数学公式本身提供机械能。人物两段自由飞行使用 g=9.81 的解析抛物线，保留水平速度，落地屈膝与翻滚为手工编排的骨骼动作。其余关节、握持和支撑是约束动画，不是通用人体动力学或碰撞仿真。

## 如何改作另一部片

保留本片的角色、求帧、声音、导出脚手架；先改实际函数与输入，再重新编排接触、镜头、飞行和声音。`next()` 会拒绝非有限值和近零导数，不能用忽略错误伪装成“任意函数可用”。改变函数后，0↔1 的二周期、−2 的收敛与现有动作时刻通常不再成立；必须重写故事和测试。
