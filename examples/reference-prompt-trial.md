# 专用提示词文本试写：投影

2026-10-27。使用 [原片仿写提示词 A/B/C](../references/reference-screenwriting-prompts.md) 自行试写，检查指令是否落到具体事件；不是独立 agent 测试、观众测试或已制作影片。没有使用原片媒体、原声或具体对手。

## 输入

> 使用原片仿写配置，围绕二维向量投影构思一次完整遭遇，并展开关键交手与发现镜头。受众能看懂点和线，但不必会线性代数；黑场、白色知识对象、橙色火柴人，无台词。此轮交付故事和关键场面，不制作视频。

## 故事构思：《你漏看了一边》

火柴人撑住一次踉跄，抬手检查指尖，注意到脚边短白线上有一个跟着手指滑动的白点。他左右晃手、上下试，白点只回应一部分动作。他踩住支座，把白线转向；松脚后轴缓慢回转，再踩住又停下。新的回应让他开始和这个“影子”玩。

短线中央的夹口也开始追着白点合拢。起初只是合空，随后整根轴转动起来，夹口的追赶逼得他护手、跳开、格挡和翻滚。他把它当成在追自己，却逐渐发现：它每次扑向的位置，总和自己真正的指尖差一截。

交手中，他利用夹口闭合时轴暂时停住的间隙，横移和抬手比较那段距离；随后沿同一投影点对应的一排位置移动。夹口继续寻找白点，找不到他。他沿这个盲区绕回一直被夹口挡住的支座，踩住早先试过的转轴，获得重新观察的时间。局势从互相追逐转为他看清这个对象究竟能看见多少。

他把右肘抵住膝上，暂时固定指尖；左手沿发光的分量描出一份短线，再把轴转到先前留过痕迹的垂直方向。第二段分量接到第一段末端，两段线的自由端终于对准真正的指尖。夹口先试着对齐这次重建的位置，他把原本准备挡击的手摊开、伸出食指；第一次准确的轻触取代合空。结尾他换个手位，主动固定并补齐两项分量，双方再次对齐，最初的游戏变成共同操作。

**本题的核心变化**：一维观测丢失的信息导致误追；重建另一分量改变互动。新能力来自对同一对象的重新表示，不能换成“找到按钮后机器停止”。夹口是否足够让观众读成寻找而非恶意，仍需动态分镜验证。

## 关键场面试写

以下是相对场面起点的时间预算，不能当作完成影片的实测时刻。

| 预算 | 背景与动作 | 可见知识反馈 / 具体后果 | 新片声音与音乐设计 |
|---|---|---|---|
| 首次操作 0–4 秒 | 只保留角色、短轴、指尖与白点。人先抬手，再横移；头在指尖与白点之间转一次。 | 白点沿轴移动，轴暂不显示公式。 | 鞋底接触与一声很轻的滑动反馈；音乐稀疏，不盖过首次反馈。 |
| 4–8 秒 | 他保持手的横坐标，屈膝再伸腿，右手抬高又放低，左手悬在白点旁比较。 | 白点留在原处。人先停手，再转头看轴；疑问来自可见的不一致。 | 手部动作不配强提示音；留出反馈未变化的空隙。 |
| 8–13 秒 | 脚踩支座、左手转轴，右手继续移指。松脚看它回转，再踩住；镜头保住转轴、手和白点。 | 白点响应方向随轴改变；脚踩支座可制动。轴后的细方向痕迹短暂保留，为第二方向留下来源。 | 抓取、转轴摩擦与短反馈；原创音乐加一个短句回应发现。 |
| 首次追逐 0–5 秒 | 夹口先在白点处合空，再转轴追来。主角先护右手，左手挡开扫来的轴，身体随接触转肩，后脚退到前脚之后。 | 首次合空交代“它对准的是投影点”；闭合期间转轴短暂停住。 | 两次夹口接触的轻重不同；第二次碰撞让音乐留出短空隙。 |
| 5–11 秒 | 人借推开轴的反力向侧面撤，夹口沿轴追来；他短跳避过低扫，落地时轴已改向，只能顺落点收身滚出。 | 对方改变轴向，刚才的躲法失效；落点迫使下一动作发生。 | 发力、掠空、落脚、轴扫过和滚翻分别对齐，不把整段统一慢放。 |
| 发现 0–6 秒 | 数次短促攻防中，他每次借闭合间隙沿当前轴的垂直方向撤一步；镜头让白点与真正的手同时可见。 | 每次轴暂时不动时，手移开而投影点没变，夹口合空。 | 复用最初的合空声音身份；把听觉重点放在相同反馈与不同处境。 |
| 6–12 秒 | 他沿刚确认的盲区绕到支座，重新踩住转轴；视线跟着手与白点之间的距离。 | 同一投影对应多个位置；先前试出的制动此时才有机会安全使用。 | 音乐降低密度；给身体恢复与关系阅读空间。 |
| 后段取样 | 他用右肘抵住膝上，固定指尖；左手把第一段发光分量描成短线，然后转轴取另一正交分量。镜头保持原点、两段线与指尖同框。 | 轴改变，第一项观测作为痕迹保留；新分量仍针对没有移动的同一点。 | 描线与转轴的接触声；配乐暂留空，让观众读这次操作。 |
| 后段拼接 | 左手保持两段线的方向和长度，把第二段尾部接到第一段端点；原本挡击的右手摊开、伸指。 | 两向量相加，自由端指到真实指尖；夹口第一次准确轻触，角色没有再退。 | 轻触声与前段强碰撞区分；音乐在触碰后回应，不提前宣布和解。 |

这些声音是新片的拟音和配乐指令，未声称原片使用了相同音色、乐器或段落。

## 参考片处理方式在本稿的落点

| 专用要求 | 本稿落点 |
|---|---|
| 身体先于知识 | 踉跄后撑住、检查指尖，再注意白点 |
| 手试规则，玩出新问题 | 横移、抬高、转轴，三个具体操作给出不同反馈 |
| 同一物件主动回应 | 最初的轴和白点继续存在，夹口对投影位置主动合拢 |
| 动作接对方回应 | 推轴撤步→对方追来→短跳→轴改向→落地接滚 |
| 安静段有新发现 | 合空间隙比较真实位置与投影位置，找到垂直方向的变化 |
| 后段用新的表示 | 保留两个正交分量，重新定位真实指尖 |
| 近距离重新相遇 | 挡击改摊掌；同一个夹口终于准确轻触，回到游戏 |

## 数学与世界约定

- 观测点 `p` 是指尖相对固定原点的位置；单位轴向为 `n`，投影向量为 `q=(p·n)n`。只在编辑明确提交后更新轴向。
- 同一 `q` 对应沿轴垂直方向的一排点，单次投影不能唯一恢复二维位置。
- 恢复位置要使用**同一位置、同一原点下的两个正交分量**，可同时采样，也可让指尖固定后依次采样：`p=(p·n₁)n₁+(p·n₂)n₂`。第一项观测需保留；本稿选择固定指尖后依次采样。不能把第一位置与另一位置的分量直接相加，也不能从本次静态拼接声称已经实现持续跟踪。
- 原点和方向痕迹不是额外传送能力。用线表示的投影允许延长到所需范围，不将有限画线的端点限制冒充数学性质。
- 轴可抓取、夹口有主动行为、闭合期间暂停转轴、支座可用脚制动，以及两分量驱动夹口，均为需要先表现的世界约定；投影运算本身不产生力或意识。
- 夹口的触碰目标、角色手脚的具体可达性和转轴速度，需要试做；文本没有证明人体受力成立。

## 自审时实际修正的缺口

1. **对方为什么暂时停手**：把首次比较安排在数次已先表现的短闭合间隙；确认盲区后才能绕到支座，使用开场试过的脚下制动进行后段取样。撤掉对手无故旁观的读图；踩踏和抓握的实际可达性仍待试做。
2. **第二条轴是否空降解法**：在初次转轴时保留方向痕迹，后段保留两项观测；增加了同一位置与原点的约束，避免把两次不同位置拼成错误结论。
3. **和解是否只有情绪标签**：用“同一个夹口从合空到准确轻触”“挡击手变成摊掌”替代文字说明。它是否会被观众读懂，尚未验证。

这次试写表明提示词能要求具体操作、攻防与后段表示变化；它没有证明整片节奏、动作或观众反应已经成立。这里只保留文本试写，不把它列为已实现 demo。
