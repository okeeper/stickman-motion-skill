# 三支 Demo 的新剧本：从疑问进入世界

状态：**待制作剧本，2026-10-26**。本文重新设计三个原主题，尚未制作动态分镜、声音小样或对应视频。时间段是剪辑预算，须在动态分镜中调整，不是已经测得的片长。

仓库目前的三个 MP4 仍是 0.8.0 的《逆向通行》《最后一扇》《转过死角》，原规则卡和 [制作规格](../demos/PRODUCTION.md) 继续对应那些成片。本文不替换已发布影片的检查记录。

参考 [Animation vs. Math](https://www.youtube.com/watch?v=B1J6Ou4q8vE) 的叙事方法：陌生对象引起注意，试探得到具体反馈，反馈改变理解，旧发现成为下一步的手段。这里重新创作人物处境、物件和镜头，不沿用原片的具体冒险情节。原片的心理动机与段落划分属于我们的观片解读。

## 三支的区别

| 原主题 / 场景 ID | 新片名与预估长度 | 最初的疑问 | 发现怎样改变行动 | 结尾的回收 |
|---|---|---|---|---|
| 负数与方向 / `negative-ride` | 《别追，等它回来》／约 75 秒 | 这个会滑走的箭头，为什么拉一下反而更难抓住？ | 从用蛮力拦截，转为利用反向所需的时间安排会合 | 开始伸手总差一点，最后放手也能接住它 |
| 二分查找 / `binary-search` | 《谁在敲门》／约 85 秒 | 小白框为什么会回应我的敲击？ | 发现通口按地址排列，通过比较逐次缩小寻找范围 | 找到的通口通向手里的白框，回声有了来源 |
| 复数旋转 / `complex-rotation` | 《世界的侧面》／约 90 秒 | 这根白杆上的小夹片能做什么？ | 被带离落脚处后，认识转向规律，主动换握点、收近支点再返回 | 开头只有一根横杆，结尾才看见自己走过一整圈 |

三支各自成立，不要求按顺序观看。主角都像一个进入陌生环境的正常人：会先看，会保护自己，会记住结果，也会在安全感增加后产生玩心。算术知识可以已有；需要探索的是这个世界如何响应操作。

## 共同的画面、表演与声音约定

- 极暗背景，橙色主角，白色可操作对象。第一镜只建立落脚处和一个陌生对象。后续结构从同一物件展开、从一次接触被点亮，或作为运动留下的痕迹出现。
- 公式只在对应操作附近出现。先看到输入和操作，再看到结果；不在开场放满终点、规则、坐标轴和任务提示。
- 每次观察都带有具体身体行为：贴近听、绕到背面看、拿在手里比较、试着松开一点重量。空心圆头通过朝向、距离、肩髋关系和手的迟疑表达注意力。
- 信息停顿与动作执行分别定时。观众需要读数、判断和等待时让镜头停住；奔跑、接触、起跳、翻身与落地保持正常速度，帅感来自时机和衔接。
- 抓住以后要继续承重，释放以后要保留动量。发生摔落，先有保护接触，再有滚动和恢复；下一镜继承刚才的位置、速度和疲劳。
- 脚步、鞋底擦地、手掌接触、布料与呼吸承担身体真实感；数字求值、空间展开等虚构现象另有克制的设计声音。速度过零时，滑行声音也经过减弱和换向。
- 不用持续音乐填满判断过程。关键反馈前适当收掉音乐，保留接触声和环境余响；高潮可增加节奏，不能遮住落脚与抓握。

## 01 · 《别追，等它回来》

### 故事

一枚白色箭头贴着地面滑行。主角想把它拿起来看看，几次伸手都只差一点。他终于抓住后端，以为能把它拉停，却压到了藏在尾部的扳片。箭头先继续向前，随后突然把他往相反方向带走。他踉跄、用手护住身体，翻滚着脱开。

他起身后没有再扑上去，而是沿着箭头的路线跟了几步，观察扳片露出的 `×(−1)`。第二次操作时，他留着脚下余地，亲眼看到设置从负变正，箭头却要先慢下来，再转向。他开始懂了：这不是刹车，结果也不会在身体上瞬间兑现。

一次短暂随行让他掌握了反向的节奏。他随后主动玩了一个更大胆的动作：跑到箭头前方，向它跃去，在上升段拨动扳片，然后放手。箭头还在往前滑，他已经开始下落；正当看起来会错过时，箭头返向，来到他脚下。他屈膝落上去，补一步卸掉相对速度，稳住身体。

开始是人追着物件跑，最后是人安排两条轨迹相遇。他活动一下刚才撑地的手腕，望向前方，随箭头滑入未被照亮的空间。

### 开场与物件来源

第一镜：地面只有一道很淡的基准线，一枚低矮、可承重的白箭头从画面中滑过。没有出口、缺口、低梁、轨道站台或独立控制台。

| 对象 | 如何出现 | 后续保持的身份 |
|---|---|---|
| `arrow` | 开场唯一的陌生物件；箭身顶部有可落脚的平面 | 始终是同一枚箭头，不另生成一辆车 |
| `reverse-tab` | 主角抓住尾部时，遮住字样的薄片被掀开，露出 `×(−1)` | 箭头上的同一个扳片；压下并释放提交一次操作 |
| `command-mark` | 第一次操作点亮扳片旁的设置值 `u` | 记录运动控制值，按操作变化；不冒充瞬时实测速度 |
| `motion-trace` | 滑过地面留下短暂光迹 | 只帮助看清路线，不构成新的支撑或障碍 |

### 数学、控制与动作边界

- 被乘的是一维电机目标速度 `u`，取值为 `±2`，单位是约定的世界距离单位每秒。每次扳片操作计算 `u_new = −u_old`；两次连续操作恢复原设置。
- `evaluate` 发生在提交操作时；`spatial_metaphor` 是把控制值交给有限加速度的载体执行。没有改写一个原先成立的等式，也没有把乘法当作现实中的瞬时冲量。
- 实际速度 `v(t)` 连续。箭头先沿旧方向减速，经过零，再向新方向加速；人体直到接触受力才相应改变运动。
- 三次操作的目标值依次是 `+2 → −2 → +2 → −2`。第三次是主动利用第一次、第二次已经看过的同一种反向，不引入加速倍率或新的功能。
- 高潮的起跳时刻、水平速度、触发位置、载体加速度与着台时刻需要联合求解。不得用腾空中吸附人物、改重力、瞬移箭头来凑落点。本文提出会合动作，尚未验证其具体参数。

### 这支的情绪与回收

从“只差一点就抓到了”的好奇，到意外失衡的警惕，再到耐心观察和有把握的玩心。第一次紧抓仍失去控制，最后主动松手却实现会合。落地后保留手腕的不适，让经历留下痕迹。

## 02 · 《谁在敲门》

### 故事

主角发现一个小白框，敲了两下。框里传回相同的两声。他凑近听，绕到背面看，背面却没有人。他沿接缝把外壳展开，里面连续翻出十六个带地址的通口；数字按从小到大的顺序掠过，盖板又落下。

他拿起从外壳内侧分出的薄框，转动查看，才发现内沿标着 `63`。这像一个地址。他想知道，哪一个通口与手里的框相连，刚才的敲击又从哪里回来。

他先看整排的中间，翻开读到 `31`，再看手上的 `63`。目光扫过左侧，停住：那一半都比目标小。他转向右半的中点，得到 `55`；继续缩小，得到 `70`。这次他立即收步折返，来到 55 和 70 之间唯一还没打开的通口。盖板翻开，是 `63`。

他再次敲两下，这次把耳朵贴近 63 号口，听清了通路的余响。他握着小白框，谨慎地把另一只手伸进通口。橙色指尖却从手里的白框中探出来。他本能地后缩，随后试着动一下手指，框里的手指同步弯曲。

他用探出的指尖轻敲框沿。熟悉的两声再次响起。最初的“回应”有了来源：空间把他的声音送了回来。主角看看一长排仍然存在的通口，又看看手里这个能带走的框。镜头停在他重新朝框内张望的动作上。

### 开场与物件来源

第一镜只有一个闭合的小白框，外壳可折叠，内部连接尚未可见。十六个通口来自它的内层结构；可携带的薄框来自它原有的内框。用连续展开交代身份，不以切镜凭空添一整排门。

| 对象 | 如何出现 | 后续保持的身份 |
|---|---|---|
| `folded-case` | 开场的单个白色物件 | 外壳展开后成为通口的共同边框与底座 |
| `entry-frame` | 主角展开外壳后，从内侧提起原有薄框 | 一直拿在左手，可移动；地址固定为 63，不因人物移动改变 |
| `ports[1..16]` | 内层按物理位置连续展开；各地址显露一次后盖板落下 | 位置和值保持固定；每次翻开地址盖板算一次查询 |
| `target-mark` | 通口全部闭合后，主角转动薄框，才看见内沿的 63 | 目标来自手里的物件，不是开场发布的任务 |
| `channel-63` | 只有匹配后拉开通口内盖，才显出与薄框相连的空间 | 自始就是同一条通路；不会在结尾临时换成另一种机关 |

### 数学与空间边界

数组固定为 `[2, 5, 8, 12, 19, 24, 28, 31, 37, 42, 48, 55, 63, 70, 81, 96]`，严格升序、值唯一，目标为 63。数字是地址标识，不是通口的尺寸、距离或敲击次数。

采用一基索引、闭区间 `[L,R]` 和向下取整的中点。下面的索引用于制作核对，成片不必额外显示一排索引数字。

| 第几次查询 | 查询前候选 | 中点 / 查询结果 | 判断与下一候选 |
|---|---|---|---|
| 1 | `[1,16]` | `8 / 31` | `31 < 63`，保留 `[9,16]` |
| 2 | `[9,16]` | `12 / 55` | `55 < 63`，保留 `[13,16]` |
| 3 | `[13,16]` | `14 / 70` | `70 > 63`，保留 `[13,13]` |
| 4 | `[13,13]` | `13 / 63` | 匹配 |

- 有序性由完整展开时的真实排列建立，不能只看到几个局部样本就宣布任意数组都有序。查询过程中地址和位置均不改变。
- 范围缩小发生在主角的候选判断中。未选区域仍在场，已经打开的地址盖板也保留状态。四次查询说明此例的查询过程；不把人物跑动耗时算成对数复杂度，也不把四次当成所有 16 元素目标都恰好需要的次数。
- 对 63 的相等比较、大小比较和候选更新是算法操作。它们不属于代数的 `equivalent_rewrite`；数值比较可记为 `evaluate`，将数组做成通口是 `spatial_metaphor`。
- 薄框与 63 号口之间的连接是本片的虚构空间设定，不是二分查找在现实中会产生传送的结论。盖板查询与内盖开启是两种动作；开放错误通口没有惩罚或危险，主角按地址寻找是为了确认这条连接。
- 开头的声音是同一通道的回响。结尾用自己的手复现声音，不能出现未来的敲击先传到过去的暗示。空间连接不附带时间旅行能力。
- 手部穿口需要维护同一只手的朝向、关节与接触连续性，薄框不能在确认前随镜头偷偷换位；具体空间画法尚待动态分镜验证。

### 这支的情绪与回收

前半段是想找到“回应者”的谨慎好奇；搜索变得熟练后，动作加快，但答案前重新安静下来。最后的惊讶来自对声音来源的重新理解。找到地址只是打开了现象，真正的叙事回报是看见同一只手穿过空间。

## 03 · 《世界的侧面》

### 故事

主角站在一小块落脚处旁，看见一根伸向黑暗的白杆，近端标着 `1`。杆端有一枚薄薄的夹片。他伸手掀开查看，发现夹片上的 `i`。当夹片重新扣在杆上，整根杆亮了一下，绕远端的固定支点向上转去。

他原本双手搭着杆，意外离地时本能抓紧，脚尖从落脚处滑开。上升很快，他收腿、换握，停下时才看见杆已经竖起，端点变成 `i`。最初的落脚处在右下方，伸脚已经够不到。

他先试着给一条腿找支撑，稳住后再看手边夹片与端点上的同一个字形。他主动把夹片取下、重新扣上。这次有所准备，屈肘抱近杆身。杆再转九十度，端点到了左侧，显示 `−1`。他看向远处的落脚点，开始明白：每次不是朝自己想去的地方移动，而是绕同一个支点转过固定角度。

他不再一直吊在最外端。双腿夹住杆，手依次内移，把自己收近固定支点，也把夹片带了过去。第三次旋转前，他先把身体收紧，确认双手和夹片都稳固。杆向下转，他抱着靠近支点的位置，身体受重力下垂；端点成了 `−i`，下面仍是黑暗。

他回看最初的落脚处，再看已经留下的三段淡弧，把夹片最后扣上。杆从下方向右转回；他利用身体的摆动翻身上杆，等杆稳定后沿它快走接跑，短蹬跨过末端与落脚处之间的小间隙，落地吸震。

主角坐低喘息，舒展一直扣紧的手指。镜头第一次拉到能看见整个路径：四段淡弧连成一圈，端点回到 `1`。开头只有一根横杆的世界，原来还有上方、左侧和下方。他站起来，重新把手搭上近处的杆端，望向上面。这次是主动想看得更远。夹片仍扣在支点附近，没有随落地回到他手里。

### 开场、空间与物件来源

第一镜只有局部落脚处、伸入画面的白杆和端头的 `1`。没有预先画好的圆、四个站点、电芯、插槽或出口。固定支点与杆属于同一物体，第一次激活才被光带完整交代。

| 对象 | 如何出现 | 后续保持的身份 |
|---|---|---|
| `ledge` | 开场供主角站立的小块支撑 | 始终是返回的同一落脚处；不在最后临时添一片地面 |
| `vector-beam` | 开场的一根白杆，远端暂在暗处 | 固定一端、长度不变的整根杆；粗实线表示可承重 |
| `factor-clip` | 原本扣在近端，看起来像一片薄边；掀开才露出 `i` | 可取下、携带、夹在杆上不同位置的同一个因子 |
| `origin` | 首次操作使整根杆亮起，显出原有的固定支点 | 位置固定；每次乘法选中整根有向杆，不移动原点 |
| `endpoint-state` | 开场为 1；各次旋转完成后更新 | 指示同一个端点的复坐标，不能与手里夹片的身份混淆 |
| `arc-trace` | 端点随每次运动留下四分之一段淡弧 | 只作运动记忆，不承重；最后一段完成后才成为完整圆形 |

布局以人物身高 `H` 作比例：支点为世界坐标原点，杆长暂按 `R = 2.4H` 做分镜；初始端点在 `(R,0)`。落脚处顶面在 `y = −0.7H`，左边缘位于 `x = R + 0.2H`，向右延伸。主角可从边缘伸手接近杆端；杆与旋转轨迹始终在支撑左侧，避免第四次旋转从下方穿过实体地面。比例仍需实际试做后调整。

### 数学、道具与身体边界

- 采用标准复平面，实轴向右、虚轴向上。数学单位映射为杆长 `R`，端点初始复坐标为 `z=1`；世界坐标为 `(R·Re(z), R·Im(z))`。
- 夹片每次从未夹合变成夹合，对选中的**整根有向杆**提交一次 `z_new = i·z_old`；夹在不同位置不改变被乘对象。夹片持续留在杆上不会重复触发，取下再夹合才能再次操作。
- 完成状态依次为 `1 → i → −1 → −i → 1`，模长始终为 1；在世界尺度上杆长始终为 `R`。夹片的字形、端点的状态字形和痕迹中的旧状态使用不同对象身份。
- `evaluate` 是离散乘法结果；`spatial_metaphor` 是围绕固定支点执行四分之一圈逆时针旋转。中间角度仅为展示连续变换的过渡，不宣称每一帧又乘了一次 i。等式在到位后显示。
- 原点固定，触点不是新的原点。主角向内攀移，是人体沿杆主动移动，不是乘以 i 缩短杆、改变模长或把人物变成复数。
- 人物从握点受到力，重力方向保持向下。手臂、腿和躯干随承重与惯性调整，不能只让一具直立骨架绕支点匀速转圈。
- 白杆可以承重，淡弧只记录轨迹。二者以线宽、亮度和接触反馈区分，避免观众以为主角能沿圆弧直接走回去。
- 翻身上杆、携带夹片和末端跨隙均须验证握持交接。若具体动作不可行，应调整站位、杆长或动作编排；数学旋转方向和模长保持不变。

### 这支的情绪与回收

第一次离地是本能紧抓，第二次转动有准备但仍紧张，第三次之前已经主动改变握持策略，第四次成为有把握的回程。结尾有疲惫，也有更强的探索欲。四次旋转分别承担意外、判断、调整、兑现，表演不能做成四段相同的乘坐循环。

## 制作前的文本复核与待验证项

当前完成的是剧本设计与文字层面的核对：三支各有一个最初疑问；主要物件有可追溯的来源；关键选择基于当时已获得的信息。静态复算确认了二分查询序列 `8 → 12 → 14 → 13` 和复数状态 `1 → i → −1 → −i → 1`。尚无对应的画面或声音证据支持流畅度、真实感、笑点或观众理解效果。

进入制作时，先做以下三个最能检验故事的局部动态分镜，再确定完整片长：

1. 《别追，等它回来》：一次失衡与一次空中会合，检验同一反向规则能否产生可读、可实现的身体后果。
2. 《谁在敲门》：展开时如何建立有序性，以及最后同一只手同时占据两处画面的空间交代。回声反转必须能用开头已经听过的声音复现。
3. 《世界的侧面》：首次失去支撑、向支点攀移、最后翻身回岸。验证全过程有握点，杆不穿地面，人不随数学对象刚性倒转。

完整动态分镜之后再核验：不看说明能否说出主角最初想知道什么；每次操作是否看得到反馈与反应；高潮是否使用了前面已经见过的机制；结尾是否回答最初疑问并保留探索欲。未达到时回到镜头与动作因果调整，不能靠追加字幕解释。

制作记录应单独记下实际片长、接触时刻、音效事件与审看结果。待对应成片完成后，再同步更新原主题的规则卡、发布入口与 QA；本文仍保留为设计过程的记录。
